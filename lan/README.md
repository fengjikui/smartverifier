# 观微 · 局域网工作台与图片对话

2026-10-01：默认 `/` 已升级为平板丝印检验工作台。请优先阅读 [工作台使用与部署](../docs/平板工作台使用与部署.md)、[PRD](../docs/平板丝印检验工作台PRD.md) 和 [MES 协作方案](../docs/MES接口协作方案.md)。以下保留的是 `/?view=chat` 的旧版图片对话说明及历史验证记录。新工作台独立实现任务、OpenCV 自动裁剪、复核、报告和模拟回填。

面向小米 13 Ultra 竖屏现场拍照，也可在电脑浏览器使用。此入口已连接 LM Studio；项目原有的 `/mobile` 外观对比页面仍是单独的演示原型。

## 启动与连接

在项目根目录执行 `npm run lan`（构建并启动）；构建完成后也可用 `npm run start:lan`。首次安装 Python 环境见根 README。电脑需保持运行，LM Studio 本地服务位于 `127.0.0.1:1234`。

- 手机与电脑连接同一局域网，在浏览器扫描 `outputs/lan-state/connection-qr.png`。连接信息保存在同目录 `connection.json`。二维码含本机配对码，勿提交到 Git。
- 默认端口 5188。电脑网络变化后重启，二维码会更新；多网卡时可用 `SV_LAN_IP=10.0.0.4 npm run start:lan` 指定手机能访问的地址。
- `SV_LAN_PORT=5190 npm run start:lan` 可更换端口。
- 可使用手机浏览器的“添加到桌面”保存入口，具体菜单取决于浏览器。这里没有依赖 HTTPS 的离线 PWA 安装能力。
- 扫码器若内置浏览器限制拍照，请选择“在浏览器打开”。局域网 HTTP 使用文件选择器 `capture="environment"` 请求系统相机；相册另有独立按钮。它是浏览器提示，不能保证所有浏览器都会直接进入相机。旧版聊天未调用 `getUserMedia`；新工作台在安全上下文中支持内嵌连续拍摄，普通局域网 HTTP 保留系统相机后备。

Node 监听局域网，Python 图像和对话服务只监听随机本机端口，LM Studio 也保持本机访问。此电脑验证 Node 局域网入口可达；不修改系统防火墙配置，不发布到公网。若手机无法访问，检查 Wi-Fi 是否隔离设备、VPN 是否拦截本地流量，以及系统对 Node 的入站许可。

## 使用流程

1. 拍照或从相册选择照片。保留原图，默认预览整张图。
2. 点击“取景裁剪”，单指拖动、双指缩放，使用旋转滑杆微调或左右转 90°。支持 1:1、4:3、3:4 和自由比例取景框；选择“自由”后，拖动右边、下边或右下角可独立调整宽高，宽高比会实时显示。手柄支持方向键微调；电脑支持鼠标滚轮缩放、拖动和方向键移动。
3. 点击“使用这个范围”，服务端从原图生成图片。确认后显示的图片与本轮发给模型的 PNG 是同一文件；白色角落是旋转产生的留白。
4. 输入问题，支持继续追问和更换照片。每条问题都附有实际使用的图片缩略图；历史文字保留，视觉输入只包含当前确认图片。
5. 顶部可切换已加载模型。优先选择 `sv-qwen4b`；原有 `hr-qwen` 也可用。更换模型保留对话文字。未适配模板的模型会显示不可用；网页不会自动下载或加载模型。

对话按本浏览器的配对身份保存在电脑上，刷新可恢复，右上角查看历史。不同浏览器/手机的记录隔离；清除浏览器 Cookie 后会成为新身份，不能自动访问旧身份记录。关闭网页后，已提交任务继续处理；重新进入可读取结果。“停止”会取消当前生成或排队任务。

## 取景坐标与图像质量

`POST /api/views` 接收 `image_id` 和 `viewport`：

```json
{
  "image_id": "上传后返回的图片 ID",
  "viewport": {
    "mode": "crop",
    "aspect": "free",
    "aspect_ratio": 2.5,
    "zoom": 2.5,
    "rotation": -90,
    "pan_x": 0.12,
    "pan_y": -0.08
  }
}
```

`aspect="free"` 时必须提供 `aspect_ratio`（宽 ÷ 高，范围 0.125–8）；固定比例无需此字段。发送提问后，自由比例随对话保存，重新进入该对话可恢复；尚未发送的编辑草稿不会在刷新后恢复。

`zoom` 为 1–12 倍，基于原图未旋转时铺满取景框的比例。`rotation` 单位为度，正数顺时针；`pan_x/pan_y` 是图片中心相对取景框中心的偏移，以框宽/框高为单位。参数与手机物理像素无关，服务端按同一几何映射从原始像素一次采样，不累计多次裁剪/旋转误差。

整图预览与取景 PNG 长边最多 1280，浏览器编辑用 1600 长边概览，原始照片始终保留。整图缩小时用 Lanczos，旋转取景用 Bicubic 插值，无生成式补字或超分。放大可突出原图已有细节，无法恢复失焦或压缩丢失的笔画。输入支持 JPG/PNG/WebP，最大 64 MB、8000 万像素，处理 EXIF 方向。

## 对话与资源限制

单次请求最多 650 输出 token、55 秒，禁用 Qwen 思考模式；全局逐个推理，最多 8 个活动/排队任务，降低同时满载的机会。历史最多 16 条已完成消息、5500 个字符，当前问题最多 2000 字符。超出模型上下文时返回失败，可新建对话继续。回答截断会明确提示，可追问。

`outputs/lan-state/` 存放会话、原图、裁片、配对信息与记录；均已被 Git 排除。不要在服务运行时手工修改状态文件。服务重启后未完成任务会标记失败，不会悄悄重复推理。

当前功能是图片问答与人工选区，不输出经校准的假货概率，也不自动调用之前的 Agent 图像工具。此前 Agent 自主定位、裁剪放大、旋转和反馈修正的流程继续保留，可独立运行。本次自由比例不改变这些工具或其调用方式。PP-OCRv6 small 是已部署的专用文字识别模型，尚未作为网页按钮接入，也不支持聊天。

## 验证

```sh
node --test lan/src/geometry.test.mjs
agent-tools/image-focus/.venv/bin/python -m unittest discover -s agent-tools/image-focus/tests -q
npx tsc --noEmit
npm run build:lan
```

自动检查覆盖：原始像素映射、90°旋转、双指缩放锚点、屏幕/输出坐标一致、空取景拒绝、模型仅收到确认后的 PNG、多轮历史与换图、不同设备隔离、重试幂等、串行排队、取消和重启恢复。

本机局域网地址实测 HTTP 可达；通过真实网页 API 给 4B 发送包含 A7/B9 的合成图左半边，模型回答 A7（约 2.98 秒），多轮追问回答 7（约 2.18 秒）。两轮均 0 思考 token。这是通路与选区验证，不是元器件准确率评估。已在浏览器中按 393×873 手机尺寸和 1100×900 电脑尺寸实际操作。尚未在用户的小米手机上实测相机、双指手势或软键盘。
