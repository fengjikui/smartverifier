> 版本：v0.3（按 2026-10-13 会议结论整理）
>
> 状态：业务方案持续更新；已形成 PRD v0.1 草案，待评审，尚未开始新版编码
>
> 会议方案日期：2026-10-13
>
> 文档整理日期：2026-10-17
>
> 来源：用户提供的最新方案，保留原方案的已确认与待确认边界；后续逐轮确认的内容补充到正文，并记录在第八节。

> 目标设备：HUAWEI MatePad 11.5 S 灵动款，HarmonyOS 5，11.5 寸，2800×1840，触控优先。

## 一、系统定位

- 形态：平板浏览器访问的 Web 应用（H5），质检员在产线现场使用。
- 职责：AI 丝印检测，以及将检测结果自动录入 MES，替代相应的人工检验与手工录入工作。
- 登录：通过公司 IDaaS 账号认证体系，获得人员工号／标识与可信 Token。
- 系统边界：本系统与 MES 是两个独立系统，跨域名，通过 MES 提供的接口交互。
- 回填范围（2026-10-17 确认）：只将指定检验任务的「丝印检测」项写入 MES 并保存；整张检验单仍由人员在 MES 最终确认提交。
- 设计原则（2026-10-17 补充）：所有功能从现场检验员方便使用出发，以平板触控操作为主。常用信息优先提供点选，减少手工打字；复核、查看和修正结果尽量在平板内完成。

## 二、整体流程

登录（IDaaS）→ 选择质检任务 → 拍摄待检照片 → AI 检测 → 结果概览（可选人工复核）→ 提交结果到 MES。

| 步骤 | 使用者动作与系统行为 |
| --- | --- |
| ① 登录 | 通过公司 IDaaS 认证，取得人员身份与可信 Token。 |
| ② 选择质检任务 | 调用 MES 接口①，按人员身份获取任务列表；选择任务后自动关联正品基准。 |
| ③ 拍摄待检照片 | 拍照或从相册选图，支持多张、删除和继续添加；已识别后也可继续补拍。 |
| ④ AI 检测 | 先定位元件、裁剪并旋转摆正，再使用关联的正品图片与描述，调用 VLM 识别丝印并比对；补拍后只识别新增部分，保留已有结果。 |
| ⑤ 结果预览 | 展示检测结果，人工复核／修正为可选入口，不必逐项确认；可返回补拍并再次识别。 |
| ⑥ 提交到 MES | 检验员点击「提交结果」表示本次检测完成，调用 MES 接口②回填完整结果及附件等信息。 |

拍摄、识别和核对可以多次往返。一次识别结束不代表整个检测任务结束；本系统不预设应检元件数量，由检验员自行决定拍多少个、何时提交（2026-10-17 确认）。

**原来的「选择／添加正品基准」步骤取消。** 正品基准由正品数据库自动关联，质检员无需手动选择。

## 三、正品数据库（已确认）

### 3.1 数据内容

| 字段 | 说明 |
| --- | --- |
| 物料编号 | 与质检任务关联。 |
| 供应商名字 | 与质检任务关联。 |
| 正品图片 | 检测参照图。 |
| 描述 | 自由文本形式的检测指导标准，包括重点关注内容、可变且允许的差异、应忽略的内容等；管理员录入标准时特别注明这些例外，作为模型的额外提示（2026-10-17 补充）。 |

### 3.2 主键与自动关联

- 正品基准主键由「物料编号 + 供应商名字」共同组成。
- 当前先按每组「物料编号 + 供应商名字」对应一套正品标准考虑，暂不展开同组多套合格丝印样式（2026-10-17 暂定）。一套标准内的图片数量与呈现细节尚未由本条约定。
- 当前关联维度只有上述两个。
- 质检任务包含任务单号、物料编号、供应商名字。
- 选择任务后，通过物料编号与供应商名字自动关联正品基准。
- 若找不到对应正品基准，提示「缺少正品基准，请联系管理员」，暂时不能检测；等管理员补齐基准后再继续（2026-10-17 确认）。

### 3.3 维护方式

- 由专门的管理员录入、维护。
- 不提供任意人员拍照上传正品记录的能力。
- 检验员不能通过自行上传正品图片来绕过缺少基准的限制；补录由管理员完成（2026-10-17 确认）。
- 部署后提供独立管理界面，管理员在其中添加数据。
- 增删改查必备。
- 批量导入如有成熟、方便使用的方案，可提供；具体形式待讨论。
- 正品维护需有操作日志，能查询谁在何时更新了哪个记录，以及字段和图片的变化；日志由服务端自动记录，历史检测依据保留（2026-10-17 补充确认）。
- 少量管理员先采用 IDaaS 登录＋服务端稳定人员标识白名单的设计默认；初始管理员通过部署配置建立，权限维护留痕，不另建一套管理员密码（用户委托助手选择常规实现）。

## 四、MES 接口（已确认两个业务接口）

目前已明确接口用途和主要数据，具体认证方式与协议细节仍有待确认项，见第七节。

### 4.1 接口①：人员关联的质检任务列表

- 触发：本系统登录后，携带人员身份标识与可信 Token，向 MES 请求。
- 返回：当前人员关联的质检任务列表。

每条记录包含：

| 字段 | 用途 |
| --- | --- |
| 质检任务编号 | 选择与关联检验任务。 |
| 物料编号 | 自动关联正品基准。 |
| 供应商名字 | 与物料编号共同关联正品基准。 |

### 4.2 接口②：上传最终检验结果

- 触发：检测完成后，提交最终检验结果。
- 操作范围（2026-10-17 确认）：回填并保存该任务的丝印检测项，不触发整张检验单的最终提交。回填接口应完成该项内容的保存，具体接口保存行为待对接核实。

| 参数 | 说明 |
| --- | --- |
| 检验单号 | 例如 `IQCF26090500016`。 |
| 检验结果 | 本系统只使用合格／不合格（2026-10-17 确认）。MES 原有枚举还包含不确定／不涉及，本系统不使用这两项；对外核实事项见独立沟通清单。 |
| 附件 | 检查照片与检测结果报告。报告采用图片与文本的 Markdown 方向，具体形式待讨论。 |
| 不良数 | 按不合格元件个数统计，不按照片张数统计（2026-10-17 确认）；合格时接口填 0 还是留空，待对接确认。 |
| 人员信息 | 操作人。 |
| 可信标识 | 可能由流程自带，不需要单独传递；待确认。 |

对外核实事项见[业务与 MES 待确认事项](业务与MES待确认事项.md)。MES 的完整枚举范围不等同于本系统应提供的检验结论范围。

## 五、各环节详细说明

### 5.1 登录

- 使用公司 IDaaS 账号认证体系。
- 登录后取得人员工号／标识与可信 Token。
- 后续向 MES 请求时，使用可信 Token 验证身份。
- 具体认证协议、Token 有效期、刷新与传递方式待确认。

### 5.2 选择质检任务

- 调用 MES 接口①，按当前登录人员关联任务。
- 任务量级不大，全部列出。
- 支持关键词查询，范围包括任务单号、供应商名字、物料编号。
- 单号通常是最后几位不同，关键词应能帮助快速过滤。
- 具体模糊匹配规则待确认。
- 列表需标记任务是否已有检测结果，例如已检测／未检测。
- 选择任务后自动关联正品基准。
- 没有关联到正品基准时，提示「缺少正品基准，请联系管理员」并暂停检测；管理员补齐后才能继续，检验员不自行上传正品图片（2026-10-17 确认）。

### 5.3 拍摄待检元件照片

- 点击添加图标，选择拍照或从相册选图。
- 支持多张照片，可删除不合适的照片，也可多次继续添加。
- 每次添加照片后可点击「检测」，上传到本系统服务并识别；不要求将整个任务的照片一次拍完（2026-10-17 补充）。
- 不设置固定应检元件数量，由检验员自行决定本次检测多少个元件，以及何时结束。
- 后续向业务方核实是否有任务应检样本数规定；如果存在，再讨论数量来源及提交校验方式。当前不自行设定数量门槛，见 BIZ-04（2026-10-17 补充）。
- 已识别后可继续补拍并追加识别。例如先拍 8 个并完成识别，再补拍 2 个时只识别新增的 2 个，之前 8 个的结果保留，不重复识别（2026-10-17 确认）。
- 照片模糊到无法判断时，为该照片标记「图片质量过低，请重新拍照」，引导使用者重拍（2026-10-17 确认）。
- 单张照片支持一个元件，也支持多个元件；多元件拍摄的前提是各元件仍足够清晰（2026-10-17 确认）。
- 当前按每个元件只拍有丝印的一面考虑。照片不清晰需要重拍时，替换对应的原照片，不作为新增元件重复统计（2026-10-17 确认）。
- 多面拍摄不纳入当前已定范围，先记入[业务与 MES 待确认事项](业务与MES待确认事项.md)，后续向业务方核实。
- 单张多元件的建议数量和上限暂不确定。用户计划拿到目标平板后，实拍 4 个、6 个、8 个等摆放情况，依据清晰度再约定；这些数量是测试档位，不是已经确定的容量要求。
- 已检测任务支持重新检测：可在新一轮检测中清空照片重新拍摄，也可复用已有照片、只调整部分后重新提交；保留之前的检测记录，不因新一轮清空照片而删除历史。具体交互待讨论（2026-10-17 补充）。

### 5.4 AI 检测

- 检测前处理（2026-10-17 确认）：无论照片内有一个还是多个元件，先识别元件位置，再分别裁剪元件区域，并旋转摆正，尽量减少文字歪斜。
- 送入模型的是处理后的元件区域，结合正品基准完成识别与比对。原始照片与处理后图片分别保留，供报告及人工核对使用。
- 元件定位、裁剪和旋转摆正在送入模型识别前完成；是否拍照后立即启动处理，以及具体技术选型，留待后续设计。
- 使用自动关联的正品图片与描述。
- 调用 VLM 识别丝印并与正品比对。
- 检测范围包括丝印文字、Logo、排版，以及元件本身的外形、颜色等特征；这些差异都可能参与合格／不合格判断，但存在可变且允许的差异，不能把所有差异一律判为不合格（2026-10-17 确认）。
- 标准中的重点关注项、允许变化与忽略项，以管理员录入的文字说明提供给模型。
- 支持检验员现场为本次任务补充文本检测说明，补充通用要求或正品标准说明未涵盖的实际情况；若检测要求存在冲突，本次以现场检验员的说明为准，并在报告中显著说明冲突及所采用的依据（2026-10-17 确认）。
- 模型的检测依据包含通用检测要求、正品图片及标准说明、本次任务补充说明。现场补充作用于本次任务，不因此直接修改正品数据库，并随本次检测记录保留以便追溯。
- 现场补充的输入方式遵循平板便捷操作原则，尽量减少打字；具体入口、提示方式与语音辅助在后续交互设计时确定。
- 本次补充说明修改后，已识别的元件也按最新说明重新判定，复用现有照片，不要求重新拍摄；同一轮结果应采用一致的最新说明（2026-10-17 确认）。
- 无法判断的模糊照片不生成合格／不合格结论，不以这种质量问题回填 MES；照片质量标签不属于检验结论（2026-10-17 确认）。
- 质量检查的时机与技术方案暂不确定：可在识别时反馈，也可考虑前置轻量模型等方案，留待后续设计；本轮不决定采用哪一种。
- 会议方案认为识别能力已验证：效果相对依赖照片清晰度，肉眼可良好识别的照片，AI 检测表现良好。本文保留该业务判断，尚未补充量化验收指标。
- 良品只需能够标记出来。
- 编号用于在照片、处理后的元件图与检测结果之间建立对应关系，展示要求见第 5.5 节（2026-10-17 补充）。
- 支持同一任务内分次识别：检测依据未变时，未变动的已识别部分复用已有结果，补拍只识别新增部分；补充说明修改时，已有元件也按最新说明重新判定。重拍替换照片时需更新被替换部分的识别结果，不沿用旧照片结论（2026-10-17 补充）。
- 元件判定输出置信度及原因，结合清晰度、S／5 等易混字形和与正品图的对比证据评估判断把握；不能只以 OCR 字符串不一致判断（2026-10-17 补充确认）。
- 清晰度勉强但仍有明确结论时可降低置信度并提示建议复核；实际无法得出结论时仍进入待重拍／待处理，不能仅靠一个低分绕过完整性校验。阈值可配置，待样本验证，详见[复核与改进设计](检测复核与持续改进设计.md)。

### 5.5 结果预览与人工核对

- 正常通道以 AI 的明确有效结果完成检测并提交；人工复核／修正是可选能力，应容易发现但不占据主要注意力，不要求逐个元件确认（2026-10-17 最新要求）。
- 本系统的检验结论只有合格／不合格，不使用不确定／不涉及（2026-10-17 确认）。
- 任务结论汇总规则：未人工修改时采用有效 AI 结果，人工修正后采用本次人工结果；同一任务任意一个元件不合格，整体即不合格（2026-10-17 确认并补充）。
- 不良数按最终不合格元件个数汇总，不按照片张数统计。例如一张照片中有两个不合格元件，就记两个；人工修改后相应更新汇总，不要求未修改的元件先逐一人工确认。
- 有明确有效结论但低置信度时特别标记「建议复核」，人员可选择保持或修正；低置信度本身不作为强制人工确认的提交拦截条件。
- 检测报告形式为图片与文本的 Markdown，具体内容与呈现细节后续讨论。
- 报告需体现检验员自定义的本次检测说明。若现场说明与标准冲突，在报告开头的显著位置优先列出冲突内容，并明确表明「本次按现场检验人员的指示进行检测」（2026-10-17 确认）。
- 冲突说明应让阅读者清楚了解原标准要求、现场补充要求及本次实际采用的检测依据；保留现场说明与操作人员信息，不因采用现场要求而改写正品库中的正式标准。
- 报告展示方向（2026-10-17 补充）：一是列出裁剪、旋转后的元件图；二是在原始照片中框出元件，以外置编号配合引导线指向对应元件。是否同时展示这两种形式，留待后续设计。
- 编号与引导线应避开丝印内容，便于人工复检；每个编号需能对应到该元件的识别内容、判定结论等结果。
- 结果与报告应区分 AI 结论、原置信度和人工最终结论，低置信度和人工修正可追溯；AI 原分数不直接充当人工结论的置信度。

#### 平板复核与人工修正（2026-10-17 确认）

- 允许检验员修改元件的判定结论，最终以检验员核对后的结果为准。
- 保留 AI 原始判断、人工修正后的结论、修改人和修改原因，便于追溯；人工修正不覆盖 AI 原判。
- 人工修正需额外标记，后台可搜索并按批次核验，关联当时图片、AI 原判及置信度、检测说明和操作记录；不直接把所有人工改判认定为模型错误。
- 在平板上直接提供便捷修正入口，不要求检验员转到电脑端才能改判。
- 预览需便于总览各元件的缩略图与判定结果，并能清楚发现异常；可进入单个元件详情，清晰查看图片、识别内容及结论，再进行修正。
- 检验员可通过照片核对，也可能直接拿起实物核对，不要求必须先在界面内放大图片才能修正。
- 修改原因优先提供快捷选项，例如「AI 识别错误，人工核对后修正」，选中即可记录；允许自愿补充说明，减少必填文字输入。
- 补充说明应支持便捷语音输入；具体使用系统输入能力还是应用内能力，后续结合目标平板设计与验证。
- 具体页面布局、修正按钮、原因选项和交互细节留待后续设计，本轮仅确认能力与便利性要求。

### 5.6 提交结果到 MES

- 调用 MES 接口②，上传检验单号、检验结果、附件、不良数及人员信息等。
- 检验员点击「提交结果」才表示本次检测全部结束，并发起 MES 回填；单次识别结束不会自动结束任务或自动回填。提交内容汇总本次任务各次识别及人工核对后的结果（2026-10-17 确认）。
