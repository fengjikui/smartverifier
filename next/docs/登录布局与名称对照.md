# 登录布局与名称对照

2026-10-18。场景为明亮工厂检验台，检验员拿平板进入检测工作台；保留已确认的红白视觉和熟悉的登录操作。

## 查看方式

打开 `/inspections/marking/preview/tablet?screen=login`，默认显示竖屏上下方案。顶部可以切换左右／上下、横屏／竖屏及候选名称。选择会写进当前地址，刷新或复制链接后可恢复同一方案。

- 左右方案：保留已确认的品牌说明区与登录区并列布局。
- 上下方案：品牌与说明在红色顶部，登录操作居于下方白色区域；根据横竖屏调整间距，短横屏也保留完整按钮和说明。
- 名称：现名“观微”；候选“鉴微”，强调细节比对；候选“明鉴”，适合后续多种检测任务的统一品牌。

正常检验端仍默认“观微”与原布局。候选只在设计预览页展示，正式选择后再统一更新系统名称；其他业务页面不受布局试验影响。

预览页与正常流程复用 `LoginScreen`。进入对照页不退出已有登录、不新建检测；点击“进入本地试用”仍调用现有登录接口，再进入正常检验流程。它不是绕过企业认证的入口，当前仍属于明确标注的本地试用认证阶段。

## 验证

- 类型检查、生产构建及路径 HTTP 回归通过，新预览页沿用规范前缀，旧地址仍不开放。
- 浏览器检查 840×1280 竖屏与 1280×840 横屏，两种布局均可完整看到登录按钮；上下方案根容器高度分别为 1280px、840px，无额外内容溢出。
- 三个名称可切换，布局、名称和方向均写入地址；验证从预览进入检验、退出及正常登录，正常页仍使用原布局与“观微”。
- 使用独立测试服务与数据目录，不执行模型推理，也未添加或修改检测记录。截图保存在本机忽略目录 `outputs/login-layout-review/`。
