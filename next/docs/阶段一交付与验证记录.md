# 阶段一：平板正常检验流程

> 日期：2026-10-17。状态：本地闭环已实现并自测，可交给用户试用。

## 怎样试用

1. 电脑打开 `http://127.0.0.1:5190/`，同一局域网平板打开本机当前 IP 的 5190 端口。
2. 点击「进入本地试用」，选择 `IQCF26090500016`。
3. 点击「用内置样例试一下」，选「四个元件」，再点击「开始检测」。
4. 观察相册状态、已完成数，点照片查看元件03的字符差异；可自行选择修正，也可直接提交明确结果。
5. 可以继续添加样例，只检测新增部分；点击「提交到模拟MES」完成本轮。成功后可重新检测，复用原来的照片。

自己的照片可以通过系统拍照入口或相册上传，原图按原始字节保存。本阶段没有接通真实图像定位和VLM，未知图片会明确显示尚未生成结论，不会被模拟成合格。内置样例只用于检验交互和业务规则，不能作为准确率证明。

## 已实现

- 新版独立前端、API服务、共享业务规则和测试目录；原有5188程序保留。
- 明确标注的本地模拟身份，任务关键词搜索、任务状态及缺少标准阻断。
- 原图上传、添加、明确删除、重拍替换、原图查看；每张最大20MB，当前接受JPG／PNG／WebP。
- SQLite服务端草稿、照片顺序与元件关联、刷新恢复；处理中离开页面不停止后台任务。
- 单个后台工作者串行模拟识别，照片角落状态、排队、按完成元件更新进度；仅处理新增或失效部分。
- 完整性校验在界面及服务端执行；质量不足、无结果或未完成不能直接部分提交。低置信度有明确结果时不强制人工复核。
- 元件详情、正品对比、等宽逐字差异、长串分段及缺字对齐；回总览保留滚动位置。
- 所有已有有效结果的元件均可人工改判，快捷原因及可选文字补充；保留原AI判断、历次AI结果、人员、原因和时间。
- 修改本次说明使原结果失效、重新判定，保留此前AI及人工历史；模拟结果不理解自然语言要求，此能力留待真实模型阶段验证。
- 图文网页报告、Markdown下载；报告包含原图、标准、说明、AI文字、人工改判及汇总。Markdown不保证颜色，原文字与文字差异说明仍保留。
- 模拟MES保存、回执、可重试失败、幂等；新轮成功后才替换上次有效结果，旧轮记录不变。
