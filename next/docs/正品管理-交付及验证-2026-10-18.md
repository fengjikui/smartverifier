## 浏览器实际试用

使用独立状态目录 `outputs/admin-acceptance-state` 和 5191 端口，与用户主试用库分离。实际操作：

1. 试用账号登录 → 新增正品 → 上传原图 → 保存并继续新增，确认物料清空、供应商保留。
2. 创建本地任务，确认自动展示刚录入的正品图与版本。
3. 进入该任务，上传待检照片，真实调用本机千问，查看元件详情，再成功提交至模拟 MES。
4. 选择完整 ZIP → 查看预检 → 确认导入 → 列表看到两条标准。
5. 标准移入回收站 → “查看详情”进入只读详情 → 单独点击“恢复标准”确认 → 标准恢复。
6. 编辑说明后版本从 v1 到 v2，维护日志展示变更记录；既有检测仍采用 v1。
7. 复制新增保留图片和说明，物料编号清空；故意填相同组合触发重复提示且输入保留，更换物料编号后保存成功。
8. 最终更多菜单使用已有组件，避免表格滚动容器裁切菜单；浏览器控制台无 JavaScript 错误。

桌面实测视口为 1280×720。另用受控 iframe 检查 840×1280 逻辑视口下的列表和编辑布局：表单变为上下区域，操作按钮仍可访问；较宽表格可横向滚动。这不属于华为平板真机验证。

本机证据：`outputs/admin-acceptance/desktop.png`、`portrait.png`，以及独立库的检测轮次和原始模型记录。截图与测试数据不作为正式标准自动写入用户库。

## 新录入标准的真实识别链路

正品图为已有生成样本裁片 `reference-crop.png`（431×419），待检图为对应 `single.png`（1536×1024），材质、丝印均为技术验证样本。

- 标准：通过管理表单实际上传，存为 `/api/reference-assets/…png`，未使用写死的演示标准。
- OpenCV 预处理：239ms。
- VLM：`hr-qwen`，模型调用约 11.106 秒。
- 识别文字：`SV358` / `A26` / `0147`，结论合格。
- 标准未录入文字，详情正确说明依据正品图比对；原图、裁片、结果、模拟回填均可查看。

该测试验证标准管理接入了真实识别，并不据此声明产线准确率。OpenCV 是受约束绿色台面的传统算法，CPU 2 线程，不加载额外检测模型；此前本机生成样片约 0.25–0.31 秒／张、Python 峰值 RSS 134–140MiB。本轮单张 0.239 秒。该数字不包含 VLM，也不代表任意背景下的定位成功率。

推理前和过程中检查资源：可用内存约 16.79–19.01GiB，CPU 采样约 3.7%–9.5%，未取得系统热／性能告警；无具体温度读数。预检也检查资源压力，图片按串行工作器处理。
