# 电脑端平板模拟试用

更新日期：2026-10-17。

## 打开与操作

打开 [平板模拟试用](http://127.0.0.1:5190/inspections/marking/preview/tablet)。这是现有检验工作台的独立预览入口，与普通网页使用同一份草稿和检验记录，不会另外复制一套任务。

建议先点击右上角「全屏体验」，获得更接近平板的显示大小。默认使用已确认原型的 **1280 × 840 CSS 像素横屏网页视口**，自动等比适应电脑窗口；也可以切换竖屏 840 × 1280，或按 100% 大小显示。旋转和调整显示比例不会重载检验页。

- 鼠标单击：相当于点按，正常打开照片、选择选项和点击按钮。
- 按住照片、列表或报告内容上下拖动：相当于手指滑动，只纵向滚动；拖动后不触发原位置的点击。
- 内层区域滑到边缘时，剩余位移继续交给外层；尊重页面设置的滚动边界，避免报告原图区域截住整页滑动。
- 滚轮／触控板：仍可正常使用。输入框、文本框、下拉选择保留浏览器原本的操作方式。
- 「刷新」只重新加载工作台，不清除已保存草稿；「普通网页」打开没有模拟外框的正常应用。

首次体验可按「进入本地试用 → 选检验任务 → 用内置样例试一下 → 开始检测 → 查看结果或报告 → 提交到模拟 MES」操作。已有已提交记录的任务，可选择重新检测；上一次有效结果仍保留。

## 当前能力边界

这是网页视口与鼠标手势模拟，并非 HarmonyOS 系统模拟器。目标平板屏幕的 2800 × 1840 是物理分辨率，不能直接当作网页 CSS 视口尺寸。实际浏览器缩放、系统栏、摄像头与相册能力仍需真机验证。

当前第一阶段是完整流程试用：身份、内置样例的识别结果及 MES 回填都是明确标注的模拟。上传自己的照片会原样保存，尚未接入新版真实模型识别。鼠标手势仅在此模拟入口内启用，正常手机／平板网页继续使用原生触摸。

手机在同一局域网也可以访问电脑的局域网地址，使用普通网页 `/`，不必套平板外框。电脑服务需保持运行，具体局域网地址以启动输出为准。
