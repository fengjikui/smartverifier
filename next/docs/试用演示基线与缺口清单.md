# 试用演示基线与缺口清单

2026-10-18，按当前 `next/` 实际代码核对。目标是先交付稳定试用与演示版本，暂停模型缓存、白板吞吐及小模型优化。

## 当前能完成什么

当前是**真实识别已接入的试用版**，尚不是公司系统联通后的正式投用版。

平板正常流程已覆盖：进入本地试用→选任务→拍照／相册上传→保存及继续添加、替换、移除照片→OpenCV定位裁剪与小角度转正→正品图与单个元件裁片交给VLM→进度与结果→可选人工改判→逐字差异与完整报告→模拟MES回填及失败重试。增量检测、修改说明重判、旧结果保留、不能部分提交等规则已有测试。

VLM连接统一为服务端配置的地址、模型和协议；保留本机LM Studio，新增公司兼容HTTP接口。新调用标记VLM来源，旧LM Studio识别记录继续作为真实模型结果显示，不会误标为预设。白板当前只展示／实验，正常业务仍按元件串行处理。

## 下周真实物料试用／演示前优先补齐

| 优先级 | 缺口 | 现状与影响 | 最小完成范围 |
| --- | --- | --- | --- |
| P0 | 真实正品标准及任务准备入口 | 新版任务和正品仍由演示数据初始化；管理员后台目前只有Figma原型。普通真实物料无法方便地建立其参照 | 先能录入一套真实正品图片、文字和说明，并绑定物料＋供应商及演示任务；之后逐步做完整管理端 |
| P0 | 真实拍摄样本与目标平板验收 | 生成图已验证技术链路，不能代替产线；绿色台面轮廓定位只覆盖受约束场景 | 目标平板验证拍照、相册、横竖屏、补拍／重拍；选少量真实型号和明确差异样品，核对定位、读字与结果 |
| P0 | 公司环境启动与模型连通 | HTTP适配已实现，真实公司地址、模型名、鉴权及Schema能力未提供 | 在公司电脑完成安装、模型请求和单件完整流程；确认局域网平板可访问。固定版本、启动说明、演示数据及复位步骤 |
| P1 | 演示数据与使用数据分开 | 当前有预设流程样例、生成拍摄图＋真实识别、真实上传三种来源 | 试用任务使用真实标准；演示任务明确标明来源。独立状态目录复位，保留试用人员数据，避免误以为预设是AI结果 |

以上不要求先把所有企业接口全部接完，足以做有明确边界的演示。若演示必须展示“从MES领任务并回填”，下述MES和登录项就提升为演示前置条件；不能把模拟保存说成真实回填。

## 真正投入业务使用的主要缺口

| 缺口 | 当前情况 | 需要的下一步 |
| --- | --- | --- |
| IDaaS登录与人员权限 | 本地模拟会话，固定试用人员；没有真实企业登录、任务授权或管理员鉴权 | 接入真实认证，服务端验证身份；管理员白名单／角色授权 |
| MES任务列表 | 新版使用初始化演示任务，没有调用真实人员关联任务接口 | 明确请求与返回字段，关联任务单号、物料和供应商，核验供应商名称匹配规则 |
| MES丝印项保存与附件 | 当前仅模拟回执、幂等和失败重试；未调用公司接口 | 联调真实保存接口、结果枚举、不良数、原图及报告附件；确认只保存丝印项、不提交整张检验单 |
| 正品数据库管理 | 新版没有真实管理员增删改查、导入、回收站和标准维护审计；设计与模板已有 | 最小录入后逐步完成原型确认功能；版本化标准并随检测保存快照 |
| 报告交付与附件可访问性 | 页面报告可看，Markdown能下载，但图像链接依赖本系统会话 | 与MES约定附件包或上传图片后替换地址；从接收端实际打开验证。完整报告字段、编号引线仍需真实照片复核 |
| 现场稳健性和运维 | 有服务端草稿、失败保留及重启恢复；未验收离线拍摄保存、弱网恢复或大并发 | 测上传中断／会话过期／服务重启；确定是否需要离线草稿。公司部署补备份、恢复、日志保留、磁盘预算与部署HTTPS策略 |
| 规模与数据保护 | 单进程串行识别＋SQLite是当前基准；没有几十至上百人容量证据；登录仍模拟 | 按试用范围控制开放，真实业务前校验权限与访问隔离；根据实测再做队列／数据库扩展，不把串行基准当成生产容量承诺 |

照片模糊时重拍、人工修正原因与AI原判保存已有；人工修正案例检索、运营分析与个人历史管理页面尚未形成完整功能，后续按PRD阶段补充，不阻断最小主流程演示。

## 建议的实施顺序

1. **本次：固定真实逐件识别基线，统一VLM配置和HTTP适配，保留可回退检查点。**
2. **下一步：最小正品录入与任务绑定，让真实物料能直接试用。** 这比继续缓存优化更能推进演示。
3. 用真实照片和平板完成一轮验收，修复实际影响操作和判断的问题。
4. 对接公司VLM、IDaaS、MES接口；如接口尚未就绪，演示清楚标记模拟部分。
5. 演示稳定后，再推进完整管理员后台、容量、白板批量识别及模型性能优化。

验收至少覆盖：正确件合格、明确差异件不合格；低质量图片不产生假结论；补拍只增量识别；现场说明重判及人工改判可追溯；有未完成照片时不能提交；回填失败明确提示且旧有效结果保留。

配置步骤见[VLM服务配置与迁移](VLM服务配置与迁移.md)。企业接口待确认项见[业务与MES待确认事项](业务与MES待确认事项.md)。
