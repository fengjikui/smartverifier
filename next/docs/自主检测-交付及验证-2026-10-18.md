# 自主检测与模拟任务：交付及验证

2026-10-18。依据用户补充：MES 接口约两个月后才能提供，先让检验员按正品发起真实识别，再在电脑 MES 手工填写结论和不良数量。

## 实现内容

- 默认进入“自主检测”，支持物料编号查询、供应商选择、查看正品原图与可选描述，点选后开始检测。
- 复用现有拍摄／相册、多图、自动定位转正、VLM 双图比对、逐件结果、人工修正与增量检测。
- 结果页突出结论与不良数量，MES 提交按钮禁用并解释原因；完成结果只存本系统，不生成 MES 回执或上传附件。
- 独立自主记录表、请求重试幂等、当前人员最近记录和完成后的冻结保护；保留已有标准版本和旧轮次。
- 模拟 MES 任务可自动关联管理端新录入的可用标准，分页按需生成列表，选择前不批量写入任务；原任务维护接口仍禁用。
- 平板模拟器支持携带已保存的检测记录 ID，便于横竖屏试用；原有 demo 链接保留。

## 自动验证

TypeScript 检查、37 项 Node 测试和前端构建通过。新增测试覆盖：

1. 同一物料的多个供应商、空描述、草稿排除和服务端分页。
2. 模拟任务自动引用实际标准、重复进入不生成额外轮次；大量标准浏览不批量生成数据库任务。
3. 自主记录不混入 MES 任务列表，开始请求重试幂等，最近记录按人员过滤。
4. 质量不合格、未处理和增量照片阻止完成，重拍替换、增量识别不改写已有结果。
5. 人工改判保留 AI 原判，结论与不良数按元件汇总。
6. 自主记录禁止 MES 提交，完成后没有 `transfer`、`effectiveRoundId` 或回执；完成重试幂等、已完成轮次不可修改。
7. 标准更新不改变旧依据，新一轮采用新标准；过期版本选择被拒绝。
8. 其他人员访问自主记录和报告被拒绝；任务维护 API 继续封闭。
