正品标准批量导入模板 v1

这是用于确认导入方式的模板草案，当前原型尚未实现上传解析。
所有物料、供应商和图片均为虚构示例，请用实际正品数据替换。

一、选择一种清单形式
Excel：在“正品标准导入模板.xlsx”的“标准清单”页填写，每行一条。
JSON：在 standards.json 的 records 中添加多条对象，保留 schemaVersion。
二者业务字段相同，不需要同时填写。
Excel 的“填写说明”页示例不会作为正式记录；“标准清单”当前为空。
JSON 示例目前有两条记录，正式使用前请替换示例。

二、字段对应
物料编号 → materialCode，必填文本，保留前导零。
供应商名称 → supplierName，必填，与 MES 中的名称一致。
正品图片路径 → imagePath，必填，例如 images/demo-reference.png。
检测说明 → description，可留空，可换行，写清检查重点及允许变化的部分。
每组物料编号＋供应商名称对应一套标准，每套当前配一张正品图。

三、图片和打包方式
图片路径相对于压缩包根目录；使用 / 分隔目录，不填写电脑的绝对路径。
把图片放在 images 文件夹，可让多条标准共用一张图。
可将一个清单与 images 一起压缩为 ZIP，或单独上传清单及图片 ZIP。
一个包只放一份待导入清单，避免同时放 Excel 与 JSON 造成歧义。
示例 JSON 标准包中已包含两条标准和一张配套图片。
“模板资料总包”包含所有格式供查看，不是可直接导入的单一标准包。

四、导入前校验方案
必填字段缺失、空白内容、图片找不到或文件内组合重复时，逐条提示修正。
图片路径只引用包内图片；不使用外部网址、不越出压缩包目录。
数据库内已有的物料＋供应商组合默认跳过，不静默覆盖。
展示可新增、跳过和错误条目；校验无错误、管理员确认后才导入。
上传限额、大小写处理、供应商名称规范及最终接口在实施时细化。

五、Markdown
Markdown 可用于编写填写说明。首轮建议以 Excel / JSON 作为导入格式，
不直接让模型从任意排版文档中猜测字段，避免多条标准之间对应错位。
