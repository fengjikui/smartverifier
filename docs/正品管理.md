# 正品管理与批量录入

更新：2026-10-30。管理端以电脑为主，独立入口为 `/inspections/marking/admin/standards`。

## 登录与权限

- 系统负责人由部署人员用 `npm run admin:owner` 初始化；随后在“人员与权限”分配正品管理员账号。普通管理员只维护正品，不能管理人员或授权。
- 管理端目前使用独立账号密码，不接公司 IDaaS。未配置账号时，本机可用 `admin / admin123` 体验，日志记为 `ADMIN-TRIAL`，该身份不能远程使用。
- 默认仅本机访问。配置独立账号后，用 `npm run admin:access -- lan` 临时开放协作录入，结束后用 `npm run admin:access -- local` 收回，重启业务服务生效。详见[人员与权限](人员与权限.md)和[部署说明](部署说明.md)。
- 管理端没有检验任务列表，也不以管理员身份查询其他检验员的 MES 任务。

## 新增一条标准

1. 上传清楚展示整个元件及丝印的图片。支持静态 JPG、PNG、WebP，单张最多 20MB / 4000 万像素。
2. 文件名按 `物料编号 型号 [供应商].jpg` 预填，多个空格视为一个分隔。解析不完整会提示补齐；不会猜旧顺序。
3. **物料编号＋型号唯一匹配**，供应商选填。去除首尾空白并作 NFC 规范化，保留前导零，区分大小写。
4. 上传后自动排队调用配置的 VLM，检查质量、实际字形歧义、丝印文字和完整元件位置，填写文字与建议。无需反复点击分析。
5. 正常清晰图片可直接保存启用。分析中或失败不能启用；可以先保存草稿。草稿中未补齐的编号／型号可以稍后填写。
6. 质量问题、难辨字形、较低识别把握分别提示。核对后选原因或补充原因；图片质量问题强制采用时保留醒目标记、模型原始分析、人员与原因，后续可筛选。

真实分析需要启动 `npm run start:real`，或配置 `SV_RECOGNIZER=vlm` 及 VLM 地址、协议、模型。未连接模型时只保存草稿，不伪造分析通过。[配置方法](VLM配置.md)。模型置信度是自评，目前低于 0.8 提示人工核对；它不是准确率或已经校准的真伪概率。

新增和编辑共用表单：标题右侧保存、取消和保存草稿，保存并继续新增直接显示；无固定底部操作栏。编号与型号一行，供应商与物料名称第二行，窄屏自动换行；丝印文字与检测说明并排且直接可见，均为选填。桌面适当增加留白，两侧面板顶部对齐、高度独立；较低屏幕自动收紧间距。分析状态位于图片下方，正常收起，问题展开，右侧不会随之拉长。分析与区域说明会自动填入检测说明，已经手动改写的字段不会被晚返回的结果覆盖。物料名称为选填。

未保存的表单输入会在本浏览器恢复。提示右侧“×”仅收起提示，保留当前图片、字段、区域和草稿；下次重新进入仍可恢复。“放弃草稿”是另一个操作，确认后才清除恢复的输入。正常保存成功会清除对应的本地未保存草稿。

标准详情将图片与资料分为主次两栏，预览区域随图片比例和可用高度调整，完整保留图像，不强制正方形或铺满裁切。小裁片会自动放大适应视窗，放大不增加原图信息；滚轮可继续缩放，双击切换放大／适应，聚焦图片后按 `0` 恢复适应。重复打开及窗口变更后重新按真实像素尺寸计算。

## 图片编辑与范围标记

列表有直接的“裁剪”“区域”“删除”入口，完整编辑页也保留工具。

- “选择 / 移动”模式中，拖空白处移动图片，点击并拖动区域移动选区；绘制模式下也能直接选择已有框。选中后拖四角缩放，拖上方圆点旋转，或在右侧“选区旋转”输入角度。方向键微移 1 像素，Shift＋方向键移动 10 像素；Delete 删除选中区域。右侧可切换忽略／重点用途，仍不允许两种用途重叠。
- 裁剪框也能拖动、调整四角；需要转正时使用上方“图片旋转”，再框选整件。切换工具不会隐藏待应用的裁剪框，可点击“重新框选裁剪”重画。
- 工具栏“撤销／重做”保留本次编辑最多 100 步，包括添加、移动、缩放、旋转、说明、删除、应用图片变换和恢复原图。一次拖动为一步，纯缩放／平移视图不记录。快捷键：Ctrl／⌘＋Z 撤销、Ctrl／⌘＋Shift＋Z 或 Ctrl＋Y 重做；输入框内保留原生文字撤销。关闭编辑器后不保留这份操作栈，标准历次保存另有版本日志。

- 所有工具模式下，滚轮以鼠标所在位置缩放；双指可以捏合缩放并移动视图，不改变保存内容。双指结束后需全部抬起，再开始画框。
- 拖动旋转环连续旋转，以当前视窗中心为中心；角度输入框可精确输入。旋转环支持方向键微调，Shift＋方向键以 15° 调整。
- 自由矩形裁剪应保留整个元件及引脚。点击“应用裁剪 / 旋转”生成派生图，已有重点／忽略框随图变换并保留，不自动重新调用 VLM；原图的质量、文字和待确认项继续沿用并留痕。也可采用模型给出的裁剪转正建议，保留完整引脚和适当留白，不强求贴边裁剪。
- 绿色重点框：**只检查框内丝印**；黄色忽略框：忽略样品对应位置的变化。两类框不可重叠。
- 区域分析能读清时生成包含具体文字的说明，例如黄色框内“0147”为可变编号；读不清时只保留位置并要求核对，不猜文字。同样的文字在其他位置出现时不会一起忽略。
- 上传原图始终保留。裁剪、旋转时框同步变换为真实四边形；如果裁剪会切掉标记，先扩大裁剪范围或主动删除不需要的标记。更换照片才清除旧框并自动分析；新增、修改识别范围会分析新规则。单纯裁剪／旋转只沿用原分析，若需要可主动“重新分析”。当前预览、详情和放大查看均能看到黄／绿框，模型输入使用同样的坐标。
- 原图查看器只显示标题旁的手势提示和图片，支持鼠标位置滚轮、拖动和双指缩放；双击切换适应／放大。取消缩放按钮和滑杆，仍保留键盘 + / − / 0。

裁剪和旋转使用传统插值，不生成或补写丝印文字。查看变换和保存变换分开；取消编辑不会改写已保存标准。

## 批量上传

推荐按文件名准备 ZIP 或 RAR；也可用 Excel / JSON 清单及配套图片。页面提供命名示例包、清单模板、JSON Schema 和填写说明。

```text
000123 STM32F407 华信电子.jpg
000124 SV358.jpg
```

只解析最后的文件名，目录名不参与字段解析。一个或多个空格均是一个分隔符；字段内部不要含空格，横杠留在字段内。仅接受当前顺序，不猜旧三段格式。

Excel / JSON 必填物料编号、型号及图片路径；供应商、说明、物料名称等选填。编号和型号用文本格式，保留前导零，不接受公式。包内最多一份清单；不要直接导入包含多个示例清单的“模板资料总包”。

限制：每批最多 2000 条、上传合计 200MB、解包合计 500MB、单个包内文件最多 100MB；进入图片库的单图仍限制 20MB。拒绝越界路径、加密包、分卷 RAR、重复文件路径和过大内容。RAR 使用进程内 WASM 解码器，不要求 Windows 另装解压命令；解包在独立受限子进程中执行。

### 重复项与暂存

- “全部”页不显示勾选列；“重复项”与其他筛选并列，不重复放一个筛选按钮。
- 已有重复按**物料编号＋型号**判断，不按供应商、文件名或图片哈希判断。默认不覆盖；重复页表头有小型全选框，仅勾选可覆盖的已有项。
- 同批多张同键图片先比较，**每组只采用一张**；不按文件顺序、目录顺序或“最后一张”自动决定。其他候选留待处理。
- 保存前明确确认覆盖数量。覆盖替换整条资料，包括空说明、文字、供应商及区域；不会悄悄保留旧图的规则，旧版本和日志继续保留。
- 已有标准在预览后被别人修改时，先暂存该条并提示重新确认，不覆盖新修改。
- 可以“保存 N 条，其余暂存”。问题、重复和未采用条目保存在服务端批次，返回、刷新、退出或重启后可继续。待处理页可补齐字段、换图、编辑区域、确认分析后再保存。
- 批次仅由原录入账号继续处理。已经保存的标准属于共享正品库；管理员协作维护仍有版本冲突保护。

完全相同的图片字节与相同区域可以复用分析；新图片或新区域使用新的分析绑定。复用不等于把不同元件的判断合并。

**此处可部分保存的是正品录入。检验任务仍须所有已拍内容取得有效明确结论后，才能完成／回填，不能部分提交。**

## 修改、回收站与迁移

每次保存、删除到回收站和恢复都保留版本、人员、时间及前后内容。维护日志“查看变更”突出真正变化的字段标题；未变化字段不会一起高亮。历史检测轮次使用当时的标准快照，不随新标准修改。

新匹配键迁移不删除原图、账号、标准版本或检测记录。旧记录缺型号或新键冲突时保留为草稿，管理员补齐／解决重复后启用；不会自动合并冲突资料。未修改的旧标准不会仅因缺少新版分析记录而被批量删除。更换图片或重新启用时执行当前分析门槛。升级前仍应按[Windows 更新说明](Windows一键更新.md)完成备份。
