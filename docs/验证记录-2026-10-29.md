## 浏览器亲自操作

管理端使用独立 `var/feedback-20261029-real` 状态：

1. 上传 `000123 SV358.png`，自动预填编号／型号，真实分析后填入三行丝印；供应商留空可保存启用。
2. 编辑快捷入口、完整表单入口、旋转环拖动与取消返回；原图放大按钮 100% → 130%；自由坐标及指针锚点另由几何测试验证。物理鼠标滚轮和触屏双指仍建议在目标设备复核。
3. 六条测试包覆盖新项、已有重复、同批候选、错误文件名及模糊图。“全部”无勾选列；重复筛选表头全选仅选择可覆盖项；比较候选后只采用一张。
4. 确认保存 2 条新增＋1 条覆盖，其他 3 条暂存；返回、刷新后继续批次正常。
5. 模糊条目填写明确测试原因后采用；人工强制采用筛选可找到，日志显示原因与操作人。该低质量标准仅存在隔离测试库，不在业务库。
6. 原有错误文件名图片仍保留，可进入条目详情补齐，不要求丢弃重传。

检验端使用同一隔离服务：录入标准 → 自主检测 → 系统相机文件选择器返回生成样片 → 完成保存 → 真实定位与 VLM → 详情 → 放大正品 → 返回 → 完成本次检测。测试没有采集电脑摄像头；文件选择器代替真实系统相机曝光。

横屏 1280×840、竖屏 840×1280 检查了详情、总览和任务入口，未见横向溢出；依据默认展开、主操作与原图缩放可达。已完成任务筛选和刷新不删除记录。

## 测试发现并修复

- 图片编辑对话框的层级问题；重复项选择和问题暂存状态显示。
- 新匹配查询补索引，避免批量检查重复项时逐条全表扫描。
- 异步分析不能覆盖人工已编辑内容；缓存复用也必须填入丝印转写；清单中明确填写的资料保留为人工输入。
- 可选供应商为空时不显示重复分隔点或空筛选项。
- 详情图片按钮的网格最小尺寸导致正品被裁切，修正后整件及三行可见；“放大正品”正确打开正品图，100% → 130% 实测正常。
- 曝光、播放、解码、编码和上传设时间边界并记录阶段；诊断分批发送、消息长度受限。
