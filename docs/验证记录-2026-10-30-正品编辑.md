# 2026-10-30 正品编辑反馈验证

本记录覆盖紧凑表单、分析触发时机、裁剪建议及区域预览。以用户最后更正为准：**上传／换照片自动分析；应用裁剪／旋转不自动重新分析。**

## 最终行为

- 新增与编辑共用表单。保存、草稿、取消在标题右侧；继续新增放在更多操作中，移除固定底部操作栏。标题操作在长内容滚动时仍可找到。
- 编号、型号、供应商默认一行；丝印文字与检测说明并排，均为选填，说明直接显示。窄屏按行排列。正常分析摘要移到图片下方，问题仍展开。
- 上传和更换图片自动分析；增加／修改区域分析新的规则与区域文字。裁剪／旋转保留原分析的质量、文字、待确认项和来源链，不新增 VLM 调用。需要时仍可手动重新分析。
- 框与图片共用坐标变换，任意角度保留实际四边形，不扩大成外接矩形。裁剪后、放大预览及已保存详情都显示黄／绿框；模型输入画同样的多边形边界，不覆盖整个框内文字。
- 裁剪会切掉已有框时明确阻止，需扩大范围或主动移除不再需要的框。新版本编辑图片可携带框反向恢复原图；旧版缺少变换记录时提示处理，不猜测位置。
- 模型给出的裁剪建议要求完整元件、完整引脚和适当留白；长引脚器件允许更多侧边背景，不强求紧贴边缘或正方形。该建议由用户主动采用，未恢复自动 CV 裁剪。
- 区域生成说明直接填入检测说明，例如“黄色忽略区内的 0147 为可变编号”。异步结果只更新空字段或上次自动填写的内容，保留正在手工修改的字段。

## 浏览器亲自操作

使用独立 `var/compact-reference-20261030/state`，普通试用管理员，本机真实 `hr-qwen` 模型，已有生成样片。未往业务库录入测试标准或管理员。

1. 上传 `TRY001 SV358.png`，物料与型号预填，自动分析返回三行丝印；供应商可空。
2. 绘制忽略区与重点区，应用后表单仍显示框；真实模型读取忽略区 `0147` 和重点区 `SV358 A26`，检测说明自动填充。
3. 先标记，再旋转 27°，框同步旋转，应用后正确对应。随后实际裁剪，框继续按新图位置映射。三行文字和说明保留，两次变换均仅派生分析记录，没有新增模型请求。
4. 保存启用，进入详情并刷新，仍有区域、文字、说明与版本日志；再进入编辑页，布局一致。
5. 放大当前检测用图，77% → 100%，两类框仍对齐。
6. 在 1280×720、1366×768 查看主表单，匹配三字段、文字、说明均直接可见；1366×768 中检测说明底部约在 506 CSS px。480×900 中字段自动变单列，主滚动区 `scrollWidth = clientWidth = 465`，没有横向溢出。窄屏需要纵向滚动，不宣称所有内容都能一屏容纳。
7. 打开编辑器后不作任何修改，直接“应用到标准”，原分析仍可用，保存按钮保持可用，不会卡在等待分析。
8. 修复编辑器 Portal 首次挂载时画布引用尚未就绪的问题，首次打开即可适应画布，并正确绑定滚轮；复测 575×571 图片初始显示约 65%，完整进入画布。

## 真实模型中发现并修正的问题

第一次同时提交两个区域时，模型只返回重点区，漏掉忽略区。运行时验证正确拒绝保存，未冒充成功。随后按当前区域数量为 `regionReadings` 设置 Schema 的精确长度及 ID 枚举，并在提示词中说明：正品入库阶段要读取所有可见文字和全部区域；忽略／重点限制只作用于未来样品检验。手动重试后完整返回两区域和三行文字。

上述为链路验证，不代表真实工厂照片的准确率；本轮未做新的 Windows 真机或 Windows CI 验收。裁剪沿用原分析也不代表模型重新验证了裁剪后的清晰度，界面会明确标注来源，仍可主动重新分析。
