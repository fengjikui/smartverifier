# 业务反馈补充确认与分阶段实施

日期：2026-10-29。承接[10 月 28 日反馈整理](反馈整理-2026-10-28.md)。本文件记录本轮已确认的规则，覆盖旧文档中与之冲突的约定；设计稿与实际实现分别记录，不把原型视为已上线功能。

## 已确认规则

### 正品匹配与文件名

- 正品按**物料编号＋型号**唯一匹配；供应商可选，不参与唯一匹配。
- 文件名只接受最新顺序：`物料编号 型号 [供应商].扩展名`，不兼容旧顺序，不猜型号和供应商的位置。多个空格仍按一个分隔符处理。
- 分析的是最后一段文件名，不把压缩包内文件夹名称当作资料字段。即使图片位于子目录，仍按文件本身的名字解析；不需要为多层文件夹另设计录入流程。
- ZIP 与 RAR 导入沿用同一规则，路径安全、解包大小和重复项仍须检查。
- 开发和演示数据可以按新规则重新整理，不为旧试用数据增加复杂兼容逻辑。公司部署中已录入的真实资料不属于本轮本机试用数据重建范围。

### 图片编辑与识别范围

- 正品列表、详情等常用位置提供编辑快捷入口；**完整编辑页内也保留**裁剪、旋转、缩放、忽略区域和重点区域等工具按钮。
- 始终保留上传原图；检测用图是可重新生成的派生图，可恢复原图后继续编辑。
- **裁剪面向整个元件**，尽量保全外形和引脚；**重点框面向需要检查的丝印区域**，两者不能混为一种框。
- 忽略框与重点框采用不同颜色，并附文字标识。重点框的含义确定为：**只检查重点框内的内容**。
- 忽略区域和重点区域**不可重叠**。当前先按矩形设计，不先扩展复杂形状。
- 换图，或进行裁剪、旋转等图片变换后，旧区域标记不自动沿用，由用户重新标记。批量列表给出「待确认」标记，详情展开说明原来有哪些标记、现在哪些需要重做。
- 查看时的缩放、平移只是浏览操作；它不改变检测用图，也不应使标记失效。与实际保存的裁剪、旋转变换区分。

### 忽略区域的检测说明

框选后生成的说明，要把**位置、框内内容和忽略的原因**联系起来。不能只泛泛地说「忽略某种颜色框里的东西」。

例如，正品图中黄色忽略框包含 `95678`：

> 正品图黄色框内的“95678”为可变编号。检测样品时，忽略对应位置编号内容的变化。

这里的 `95678` 是正品中的定位线索，不表示在整张样品图上忽略所有相同数字。模型能可靠读出时填写具体内容；无法可靠读出时保留区域定位，提示人工确认，不编造字符。生成后的说明供管理员查看和补充。

### 上传分析与启用

- 单张或批量**上传后自动开始模型分析**，无需把点击「分析」作为必经步骤。
- 分析范围包括清晰度、难辨字符和特殊符号、元件定位与裁剪旋转参数、丝印文字及相应检测说明。
- 新图或替换图片后，**必须完成本轮模型分析才能启用该标准**。不能沿用上一张图的分析结果；可先保留草稿。
- 正品图片应达到模型能清楚观察丝印的质量。光线和字符细节优先；背景不理想但能可靠定位、裁剪且丝印清楚时，不只因为背景杂乱就拒绝。
- 图片质量不够与字体本身难辨是两类问题。只有实际存在歧义的字形才要求确认，不见到 `6/b`、`5/s` 就一律拦截。
- 质量阈值的严格程度仍待讨论。先前提出的管理员强制采用能力需保留明确标记与操作记录；它不能绕过「已完成模型分析」这一前提。
- 分析时显示实际进展，例如图片已保存、定位处理中、丝印与质量分析中、待确认项已生成；不靠装饰动画或虚构倒计时表示进度。
- 分析失败、仍在分析、需要重新标记与待人工确认，要分别显示，并支持继续处理。定期重新分析的周期和触发条件尚未确定，不在本轮擅自增加定时任务。

### 批量确认与暂存

- 默认标出可能有问题的条目，支持一键筛选，进入详情逐项修改或确认。
- 一批 20 条中即使有少量条目未处理完，**可以先保存可用的其他条目**；问题条目暂存为草稿，之后继续处理。
- 需区分「暂不启用／留在草稿」与「删除」。暂存不丢原图、已填写资料及待确认原因。
- 保存时明确显示数量，例如「保存 16 条，其余 4 条暂存」，避免误以为整批都已启用。
- 重复标准默认不覆盖；用户可选择个别覆盖，或全选重复项覆盖。
- 选择覆盖时，**使用新资料整体替换**，重新分析并填写新结果；不悄悄保留旧文字、说明或区域规则。旧版本继续留档，新图片上的区域由用户重新标记。
- 此处允许分批保存的是**正品标准录入**。实际检验任务仍遵守既有约定：本轮已拍内容未全部得到有效明确结果时，不能部分回填 MES。

### 管理端与检验端

- **移除管理端检验任务列表**，系统负责人和普通正品管理员都不保留这个入口；不以管理员身份拉取所有检验员任务。
- 管理端专注正品、维护记录、回收站和授权人员管理。标准详情里与管理员全量任务查询相关的展示也一起检查。
- 检验端后续按当前检验员的可信身份获取其 MES 任务；增加未完成／已完成等状态筛选，允许隐藏已完成任务。
- 筛选仅改变显示，不等于删除任务或记录。本轮不在平板增加删除 MES 任务的行为；MES 返回状态、历史范围和刷新接口继续在对接文档中确认。
- F13 已定位为元件详情的**「检测依据与修正记录」**，改为默认展开。
- F14 位于正品管理**「维护日志 → 查看变更」**，突出实际发生变化的字段标题，保留变更前后值；未变化项不一起高亮。若与现场所指位置仍有偏差，可在试用中再次确认。

## 实施顺序

1. **需求与设计**：记录本轮规则，确认管理端图稿，启动当前服务供核对 F13／F14。
2. **数据与基本录入**：统一物料编号＋型号、供应商可选、新文件名、重复覆盖、暂存草稿及开发样例数据。同步数据库约束、接口、模板与测试，避免只改前端。
3. **正品图片及智能分析**：原图／派生图、编辑与框选、上传自动分析、待确认状态、启用约束、对应版本及操作日志。
4. **现场使用与对接**：拍照卡住的诊断与修复、原图放大、结果详情默认展开、任务筛选、维护日志高亮、MES 沟通文档与分项验收清单。

每阶段完成相应自测后创建 Git 检查点，再交给用户试用。已有业务数据和实际账号不作为自动化测试或演示重建的对象。

## 本轮仍需后续校准的事项

- 正品质量和字符歧义的判断尺度、强制采用的交互细节，以实际样片和业务试用校准。
- 同一批内部出现多张同物料编号＋型号图片时，先列出冲突，由管理员选定采用哪张；不自动以解压顺序决定胜出者。具体批量界面在实施该模块时补充。
- MES 人员任务接口、任务完成状态和保存协议仍需与对方确认；本系统未宣称真实 MES 接口已接通。
- 相机卡住的具体阶段仍需真机日志定位，不把实时取景正常等同于曝光、预览和上传均正常。
