# 2026-10-31 正品面板与图片预览验证

## 改动

- 编辑表单两列取消等高拉伸。图片与资料约为 1.05∶0.95，右侧按自身内容决定高度，丝印文字和检测说明保持直接显示。
- 标准详情以图片为主、资料为辅。图片视窗按实际比例及可用高度调整，不固定正方形；编号与型号优先，丝印文字、检测说明分组，版本信息弱化。
- 公共预览组件按图片地址隔离生命周期，取消切图后将尺寸重置为 `1×1` 的普通 effect。挂载时检查已经加载的图片，并在 `load` 时读取实际像素尺寸；图片和容器就绪后在布局阶段适应，零尺寸容器不计算错误倍率。
- 移除初始适应不超过原尺寸的限制，小裁片最多可自动放大 16 倍。窗口尺寸变化会重新适应，缩放不修改图片文件或区域坐标。

代码检查发现了上述初始化时序、未就绪尺寸和小裁片不放大的隐患，但**未在 Windows 真机复现用户原始偶发问题，不能断言其唯一根因已经验证**。
