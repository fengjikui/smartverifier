# 自主检测导航与近期页面走查

日期：2026-11-02。本轮以平板模拟为重点，没有改变模型、检测规则或数据库结构。

## 修正与设计

原正品列表是可收缩的 Flex 子项，但卡片仍保持内容高度，导致卡片溢出，与最近记录重叠。收起和展开时都可能发生。

按用户确认，移除选择页底部的最近记录，新增与“自主检测”“模拟 MES 任务”并列的“最近检测”页面。滚动内容按自然高度排列；显示物料＋型号、供应商＋创建时间、结果／草稿状态，支持查询、刷新、空态、失败与重试。

先更新 [Figma 最近检测画面](https://www.figma.com/design/6kmN9EjSyVpFuTQxC1NaBE?node-id=4317-2949)，复用原列表、导航、颜色变量和中文字体，再实现。结果颜色统一为绿／红。

从记录进入详情或报告后保留 `entry=history`，返回时仍在记录页；列表标题不再残留上一条任务信息。模拟器支持 `?entry=history` 直接进入新页。管理表单长标题换行时，两列检测文本框顶部也恢复对齐。

## 数据隔离与边界

测试标准、草稿和预设识别均在独立目录／端口创建，业务照片和结果未删除、未改判。管理测试最初共用了浏览器主机地址，影响了试用 Cookie；随后改用 `localhost` 测试域，与工作台 `127.0.0.1` 分开，并恢复正常登录。多端口本身不隔离同名 Cookie，后续界面测试须使用独立主机名或浏览器配置。

测试服务、临时页面和测试库在结束时清理。截图和日志保留在 Git 忽略的 `outputs/ui-review-2026-11-02/`，不将用户资料截图提交仓库。业务服务继续运行。

最近页仅覆盖当前账号最近 20 条自主检测，不包含 MES 任务，不代表完整历史检索已经完成；较早数据仍保存在数据库。
