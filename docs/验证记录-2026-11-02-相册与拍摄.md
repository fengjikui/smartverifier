# 相册恢复、拍摄布局与照片准入

日期：2026-11-02。以华为平板模拟的横屏1280×840、竖屏840×1280验证。业务识别仍使用原有 VLM，本轮不改变模型判断。

## 实现

- 空态、照片总览和连续采集页均提供“从相册选取”；支持多选，替换模式只接收一张。
- 网页快门放右侧，完成放标题栏右上角。系统相机自己的原生界面由设备控制。
- 同一检测轮内，对原始文件计算 SHA-256。换文件名或跨相机／相册入口重复添加均拒绝；HTTP端再次检查，返回原照片编号。重复上传请求保持幂等；替换自身允许，替换为另一已存在照片拒绝。删除后可重选，不跨任务／轮次阻断。内置预设样例属于模拟流程，不参与真实照片去重。
- 相册默认接收最近10分钟原图；服务器用 `exifr@7.1.3` 读取 EXIF `DateTimeOriginal`，有 `OffsetTimeOriginal` 时优先使用，没有时使用现场时区。拒绝缺失、无法解析、过期或晚于服务器超过2分钟的时间，不使用文件修改时间。
- `SV_ALBUM_MAX_AGE_MINUTES` 可配置0～10080分钟，0关闭时间限制；`SV_PHOTO_TIMEZONE_OFFSET` 默认`+08:00`。修改后重启业务服务。正品录入不受此限制。
- 批量选择中的拒绝项逐条说明，其他有效图继续保存。网络等暂时错误仍保留待上传队列，重试保持请求身份；队列绑定检测轮，不能误传到另一轮。
- 原图字节保持；照片及操作日志记载来源和可读取的拍摄时间。拒绝项不增加照片数量、修订号或遗留文件。

## 实际边界与待真机验证

当前为精确文件去重，不覆盖重压缩、裁剪或修改元数据后的不同文件。EXIF可编辑，H5来源字段也不能证明真实曝光；相机输出可能没有EXIF，因此无时间相机文件可用，本策略用于防误选，不能声称强防作弊。

桌面浏览器没有可用相机，本轮验证了相机失败后备和文件返回协议，没有重测真实曝光、鸿蒙原生相机按钮、相册元数据保留或VLM准确度。请在华为平板新拍一张后从相册选入，确认原图含有拍摄时间；若浏览器移除了EXIF，应提示拒绝，而非以下载时间放行。

## 资料依据

- [MDN capture说明](https://developer.mozilla.org/en-US/docs/Web/API/HTMLInputElement/capture)：H5请求设备采集的方式，原生界面由浏览器／系统提供。
- [MDN File.lastModified](https://developer.mozilla.org/en-US/docs/Web/API/File/lastModified)：文件修改时间，不等于拍摄时间，因此不作时效依据。
- [exifr 官方仓库](https://github.com/MikeKovarik/exifr)：按需读取 EXIF；`reviveValues:false`保留原时间字符串，避免依赖服务器本地时区。
