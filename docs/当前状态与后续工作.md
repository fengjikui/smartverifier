# 当前状态与后续工作

更新：2026-10-29。当前根目录为唯一维护版本，`main` 为交付分支。最新规则见[需求确认](需求确认-2026-10-29.md)。

## 已具备的试用闭环

- 检验端：自主选择正品或选择模拟 MES 任务 → 连续拍照／系统相机后备 → 保存、补拍、重拍替换／删除 → OpenCV 定位裁剪、转正 → 配置的真实 VLM 比对 → 逐件进度、结论、不良数、详情与 Markdown 报告 → 本系统完成或模拟回填。
- 单张可含多个清晰元件；按元件计数，任一不合格则整体不合格。待检、失败或需重拍内容阻止完成／回填。增量检测、说明改变重判、人工修正与 AI 原判留存、重检旧结果保留已有回归。
- 正品管理：独立账号密码、负责人授权普通管理员、增删改查、回收站、版本及维护日志。管理端不保留检验任务页面。
- 正品按物料编号＋型号唯一匹配，供应商选填。支持 ZIP/RAR 文件名导入和 Excel/JSON 清单；当前文件名为 `物料编号 型号 [供应商]`，不猜旧顺序。
- 上传自动真实分析，绑定图片及区域后才可启用。清晰度／实际字形歧义分开，问题项可核对原因后采用并留标记；分析失败或未完成不能绕过。
- 图片原图保留、派生裁剪／旋转、指针缩放、旋转环、重点／忽略区域与具体说明。图片变换要求重标，查看缩放不改依据。
- 批量同批候选每组明确采用一张；已有重复选择覆盖并留版本；可用项先保存，其余服务端暂存恢复。此规则仅用于正品录入，不允许检验任务部分回填。
- 原图放大查看、详情依据默认展开、检验任务状态筛选／刷新、拍照超时与诊断日志、Windows 更新备份及 UTF-8 路径处理。

VLM 使用服务端可配置地址、模型、协议与认证，可连本机 LM Studio 或公司兼容服务。正常业务按元件串行；白板和缓存仍为实验，不承诺批量生产准确率。
