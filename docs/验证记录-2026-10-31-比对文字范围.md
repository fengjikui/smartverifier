# 2026-10-31 需比对文字与 HTTPS 检查

## 改动

- 用户确认主要调整框选后 VLM 重新分析、自动填写文字的提示词。沿用 `lines` 字段，名称改为“需比对的正品丝印文字”，表单与详情同步。
- 有重点区：只纳入重点区内丝印；有忽略区：排除对应位置文字；无区域：转写整个元件的丝印。局部字符被排除时不补全文字；没有可比对文字时返回空数组。提示词与 JSON Schema 字段说明一致。
- `regionReadings` 仍单独读取每个区域，用于生成包含可靠原文的区域说明。忽略区文字不因此加入比对文本；不使用字符串替换过滤，避免同字不同位置被一起删除。
- 旧版带框全文缓存首次再次请求分析时重跑，保留旧分析与历史标准。当前规则的结果可继续缓存，裁剪／旋转沿用来源分析；人工改写字段仍不被自动覆盖。
- 实际样品识别的单件、整图提示词也要求 `lines` 只输出比对范围内的文字。正品图片及空间标记仍发送给 VLM，保留位置对应的证据；不额外拼接一份完整正品转写。日志记录新的提示词版本。
