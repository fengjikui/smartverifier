# 平板工作台：使用与部署

适用版本：2026-10-01。默认入口改为任务检验工作台，图片聊天在 `/?view=chat`，自主裁剪 Agent 的 CLI/MCP 工具继续保留。

## 在当前电脑试用

1. LM Studio 服务使用 `127.0.0.1:1234`，保持视觉模型已加载。工作台优先使用 `hr-qwen` 或已加载的 27B，不擅自下载、加载或切换模型。
2. 项目根目录执行 `npm run lan`；已构建时可用 `npm run start:lan`。
3. 电脑打开 `http://127.0.0.1:5188/`。首次用 `outputs/lan-state/connection.json` 中的本机地址配对；平板与电脑连接同一局域网，扫描 `outputs/lan-state/connection-qr.png`。
4. 填写试用工号与姓名，这是本地记录身份，不是 MES 登录。
5. 可先点击“试用合成样例”，系统创建四件任务并自动裁剪；点击“完成拍摄并识别”调用真实模型，不套用答案。
6. 核对异常、填写依据，确认通过或不合格，再“模拟回填检测项”。默认只保存到本机模拟接收目录。

测试照片在 `fixtures/inspection/`，是虚构样本：标准 SV358，四件照片的第 3 件为 SV385。模型可能误读，以实际结果为准，此例不能证明现场准确率。

## 使用自己的照片

新建任务，填写单号、物料和应检器件数。建立正品标准，上传清晰单件照片，可选填经核对的文字与允许变化规则，并确认来源。只有文字时，报告明确只比较文字。

优先使用浅色哑光纯色背景，一次拍一个黑色器件，完整保留引脚，避免反光与阴影。多件模式最多四件，分开摆放且每件文字清晰。当前轮廓定位主要适用于这样的受控背景，不保证任意托盘、金属件、电阻电容或拥挤背景都能识别。

- **拍照 / 相册**：上传完成才算保存。可退出、刷新后继续。未完成上传有提示和重试，不要在未保存时关闭页面。
- **自动裁剪**：从原图定位、留边、旋转，不做生成式补字。原图不覆盖，裁片与标框图另外保存。
- **定位异常**：没有找到、数量不符、目标过多，先重拍或移除处理。低清晰度不能自动通过。
- **重拍**：用“重拍”替换原照片，不把同一实物另加成新样本。相同文件被拦截；不同照片是否为同一实物仍需人工核对。
- **旋转**：展开器件，点“旋转 90°（需重新识别）”，再识别未完成项；对应旧结果失效，其他已完成件保留。
- **中断**：可停止模型生成，或离开页面。已提交的后台任务继续执行；服务重启后标记停止，人工点击继续，不悄悄重跑。
- **复核**：模型 FAIL/REVIEW、质量告警和执行错误不能自动通过。保留模型原判、复核人、时间与依据。
- **回填**：应检数与有效件数一致，全部完成并复核后才可回填；一个不合格则该项 FAIL。
- **自动回填**：建单时可选，默认关闭；仅全部明确通过且无告警、无人工干预时触发。
- **报告**：下载 ZIP，含 JSON、有效原图、标框图、裁片及参考图。冻结报告在重试时不改变。

回填仅保存丝印检测项，整单最终提交仍由人在 MES 完成。

## 相机与平板兼容

HTTPS 或本机 localhost 尝试内嵌连续拍摄；普通局域网 HTTP 使用系统相机文件入口，相册可多选。系统相机是否直接启动由浏览器决定。浏览器视频流分辨率可能低于系统相机，小字不清晰时优先系统相机原图。

正式连续拍摄建议在公司域名配置可信 HTTPS。尚无具体华为设备，不宣称真机验收完成；需验证授权、后置相机、相册、方向、中文输入、休眠及断网恢复。相机安全上下文要求见 [MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)。

## 新电脑安装

实测环境为 macOS、Apple Silicon、LM Studio。公司电脑的系统、内存、GPU 和模型格式待确认；MLX 模型不能直接搬到非 Apple 平台。启动器已区分 Windows/POSIX Python 路径，但没有 Windows 真机验收。

需要 Node.js ≥22.13、npm、uv 和兼容视觉模型的 LM Studio。当前 Qwen SDK 使用模型自身可用的 `chat_template.jinja` 并适配禁用思考；其他格式模型显示不可用时，需要适配 transport/template，不能只复制模型名称。

```sh
npm ci
cd agent-tools/image-focus
uv sync --extra mcp --extra lmstudio --extra web
cd ../..
npm run build:lan
npm run start:lan
```

模型当前固定使用这台电脑的本机 LM Studio；远端推理服务需要另外适配。

| 环境变量 | 默认 | 用途 |
| --- | --- | --- |
| `SV_LAN_PORT` | 5188 | 网页端口 |
| `SV_LAN_IP` | 自动找物理网卡内网地址 | 多网卡时指定平板可访问的 IP |
| `SV_STATE_DIR` | `outputs/lan-state` | 状态目录，可用于隔离测试 |
| `SV_STATIC_DIR` | `outputs/lan-web/dist` | 前端构建目录 |
| `SV_MES_URL` | 空 | 空值使用本地模拟；有值用 HTTP 适配器 |
| `SV_MES_TOKEN` | 空 | 服务端 MES 凭证，不进入浏览器 |

macOS/Linux 指定网络地址：

```sh
SV_LAN_IP=192.168.1.20 SV_LAN_PORT=5188 npm run start:lan
```

Windows PowerShell：

```powershell
$env:SV_LAN_IP = "192.168.1.20"
$env:SV_LAN_PORT = "5188"
npm run start:lan
```

不自动改防火墙或发布公网。访问失败时检查 Wi-Fi、AP 隔离、VPN、实际 IP 与 Node 入站许可。

## 数据与身份边界

`SV_STATE_DIR` 下保留原配对会话和聊天记录；新模块使用：

- `inspection/inspection.sqlite3`：SQLite WAL 任务、标准、审计、复核、回填状态。
- `inspection/task/`、`inspection/reference/`：原图和派生文件。
- `inspection/mes-receiver/`：默认模拟接收记录和附件。

二维码与连接码也在状态目录，不提交到 Git，不共享给无关人员。备份前正常停止服务，再复制整个状态目录，含数据库关联文件与图片，不能只复制 SQLite 主文件。首轮不自动清理证据；容量监测、保留期、备份和权限回收由公司 IT 确认。

每个浏览器 Cookie 是独立试用身份，不同设备不共享任务或标准。清除 Cookie 不能自动恢复旧身份。这不是生产多人权限方案；正式部署需企业 SSO、任务授权与公共标准审批库。当前阻止用本地试用身份或合成资料向非本机真实 MES 回填。

## 性能与扩容

照片保存与推理分开：图像处理串行，最多四个上传进入处理队列；模型串行，最多 100 个检验任务排队。超额返回忙碌，前端保留未保存照片供重试。资源或热压力高时停止本次处理，保留已完成结果，不结束用户其他进程。

本机四件双图实测每件 10.65–11.39 秒，共 46.9 秒，尚未达到每张几秒。这不是 P90 或多人容量评估；一张四件会执行四次识别，不能按单件耗时算。排队与每件模型耗时分别记录。

几十至约百人在线不等于百路同时推理。公司部署前要测峰值任务/分钟、每批件数和可接受排队，再确定集中数据库、持久队列和多个推理实例。当前单机队列不代表百人并发验收通过。

接口格式、联调接收器与备选方案见 [MES 接口协作方案](MES接口协作方案.md)。
