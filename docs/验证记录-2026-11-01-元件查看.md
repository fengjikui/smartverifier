# 元件聚焦与原图编号验证

日期：2026-11-01。范围为检验详情、原图弹窗、页面完整报告；不改变识别管线、模型参数、统计和原始照片。

## 实现

- 详情的样品位置按当前元件 `bbox` 展示原图局部，留适量像素边距；邻件接近时缩短相应方向的留白。没有有效位置时保留整图。旧记录已有的转正裁片仍可显示。
- 点击样品或“查看原始照片”打开整张照片；全部有效位置显示框和两位编号，当前元件突出。优先将编号放在框外；图边、密集排列时退到框边，不将编号放在元件中央。深色底增加浅色衬边。
- 详情导航、原图及页面报告使用本轮跨照片连续编号；内部仍以元件 ID 和来源照片关联。报告保留来源照片编号，Markdown 原有的来源标识不变。
- 点击原图编号回到对应已完成元件详情，支持鼠标和 Enter／空格。灰色待检测项不提供详情跳转。
- SVG 引用原照片像素，只改变浏览窗口；框与照片使用同一变换。滚轮、拖动、双指逻辑沿用公共查看器，编号字号随倍率补偿；不生成新裁片、不重新推理。

Figma 可编辑稿：[单元件聚焦对照](https://www.figma.com/design/6kmN9EjSyVpFuTQxC1NaBE?node-id=4310-2870)、[原图编号定位](https://www.figma.com/design/6kmN9EjSyVpFuTQxC1NaBE?node-id=4310-2915)。本轮后续截图读取遇到传输关闭，最终界面以以下浏览器实测为准。

## 测试数据及边界

浏览器数据置于独立的 `var/component-view-qa/state`，端口 5198，通过 `localhost` 与日常 `127.0.0.1` 试用 Cookie 隔离。使用仓库生成样片及明确标记的预设结果，没有向用户实际数据库添加测试记录，也未调用真实模型。截图保存在同目录的 `screenshots/`，均不提交到 Git。

位置展示依赖已有检测结果的 `bbox`，本轮不证明 VLM 的实际定位准确率；框若不准，仍可展开整图检查。密集或接触边界时可能无法给每个编号腾出独立背景，采用框边退让。双指的几何算法有回归，华为平板实际捏合仍需真机验收。本轮不验证 Windows 或公司内网环境。
