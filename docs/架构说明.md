# 鉴微当前架构

浏览器只负责拍照、预览和操作。Node 服务统一处理会话、正品、检测轮次、草稿、审计与报告；Python 子进程执行图片处理及模型传输。前端和 API 同源部署，后续改为鸿蒙或 WeLink 客户端时可复用业务 API，摄像头及认证接入按宿主重新适配。

## 代码边界

- `web/src/App.tsx`：检验主流程；`admin/`：独立正品管理；`model-debug.tsx`：本机调试。
- `server/index.ts`：HTTP、静态文件、会话及上传；`service.ts`：检测轮次与队列；`store.ts`：Node SQLite。
- `server/admin/`：标准版本、维护日志、文件及 Excel / JSON / ZIP / RAR 预检、模型分析队列与批次草稿。
- `server/vision/local-pipeline.ts`：前处理及识别适配；`local_worker.py`：绿色台面定位、裁剪与转正；`vlm_client/`：LM Studio、兼容 HTTP、提示词与时序追踪。
- `shared/`：契约、路径、状态、按元件汇总和文本差异规则。服务端负责提交门槛，不能仅依靠前端按钮限制。
- `server/mes/mock.ts`：当前模拟 MES；没有实际公司任务接口或回填适配器。

## 数据与处理

选择正品或模拟任务后建立检测轮次。照片按拍摄顺序保存，定位后逐件处理。新增照片只识别新增部分；补充说明变化使既有判定失效，复用照片重新识别。人工修正保留 AI 原判、操作人及原因。结论按元件数量汇总，任一不合格则整轮不合格；未完成或需重拍内容阻止提交。

SQLite、原图、裁片、报告与调试记录默认放在 `var/data/`。标准以物料编号和型号关联，供应商可选，轮次保留当时标准快照。备份应停止服务后复制完整状态目录，不能只备份数据库而漏掉图片。自主检测完成只保存本系统，MES 按钮禁用。

## 配置和开发

- `npm start` 加载根目录 `.env.local`；`npm run start:real` 显式启用 VLM。
- `SV_HOST`、`SV_PORT`、`SV_STATE_DIR`、`SV_RECOGNIZER` 是当前通用服务配置；旧 `SV_NEXT_*` 不再使用。
- Node 24 直接执行 TypeScript，Vite 只构建浏览器代码到 `dist/`。Python 依赖统一在根目录 `requirements.txt` 和 `.venv/`。
- `npm run dev` 启动 Vite 热更新，在另一个终端运行业务服务；默认转发 API 到 5190。
- `npm test` 与 `npm run test:python` 使用临时数据和测试 HTTP，不调用真实模型。

## 当前限制

只有 CPU OpenCV 定位器，主要适合绿色防静电台面、分离摆放的深色封装，复杂托盘或遮挡需要实拍验证。识别串行，在线人数不等于模型并发容量。图像定位和模型调用分别记录真实耗时，Schema 与元件 ID 均需通过验证。

检验员身份仍为共享本地试用；管理员独立账号密码不是 IDaaS。企业认证、任务授权、正式 MES 幂等回填、生产 HTTPS 和多人容量是后续工作，不能把当前局域网试用直接视为正式上线。

## 正品分析与图像规则（2026-10-29）

`server/admin/analysis.ts` 持久化分析状态，绑定图片标识与区域指纹；新图、区域变更不能复用旧分析启用。`server/vision/reference-analysis.ts` 使用配置的 VLM 和 JSON Schema，服务端再次验证结构、坐标与区域编号。`model-slot.ts` 让管理分析、检验和调试共用一个串行推理槽位，避免本机并发压满模型。服务重启将未完成分析标为失败，可重试。

原图保留；`edit_worker.py` 生成裁剪／旋转派生图，不生成字符。绿色重点区只检查区内，黄色忽略区仅忽略对应位置变化；规则、区域图和可靠读到的文字送入后续比对，轮次保存标准快照。

批量导入先预检，再后台分析，最后事务保存选中且可用条目，其他留在 `reference_imports` 服务端草稿。同批重复单选，已有标准覆盖检查版本；已保存行不会重复写入。RAR 用独立 Node/WASM 子进程内存解码、受控写入临时数值文件，Python 继续执行统一图片校验和命名解析。

浏览器相机关键阶段设超时，ImageCapture 无响应会回退视频帧；诊断只记录阶段、耗时、尺寸、处理编号和错误，不包含照片字节。记录在浏览器保留最近 200 条，并向已鉴权服务发送有界日志，服务端按文件大小轮转。真实华为浏览器的曝光链路仍须按验收表执行。
