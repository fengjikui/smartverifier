# 从管理员录入到平板检测：完整试用清单

更新：2026-10-30。供人工按顺序操作，适用于当前 `main`。每项包含操作与预期结果；通过后勾选，有问题记录项目编号。**未测试的项目保持未勾选，不视为通过。**

第一遍按 **P → A → B → D → E → F → G → H** 跑通日常流程；第二遍补测 C 和 I。没有实物或可用模型时，标记“受阻”，先测试不依赖它的项目。

已有工程分级、自动测试命令及真机专项见[分级测试与验收](分级测试与验收.md)。这里是给使用者逐项操作的清单，不要求先读代码。

## P · 准备环境与资料

- [ ] **P01 更新并启动。** Windows 先正常停止服务，再双击 `update-windows.cmd`；显示更新完成后，在原项目目录运行 `npm run start:real`。预期：启动成功，原账号和已有正品保留。配置／备份方法见 [Windows 一键更新](Windows一键更新.md)；真实识别需 VLM 服务在线，地址配置见 [VLM 配置](VLM配置.md)。
- [ ] **P02 记下地址。** 电脑管理端为 `http://127.0.0.1:5190/inspections/marking/admin/standards`，检验端为同一主机的 `/inspections/marking`。端口如有修改，以启动输出为准。平板使用服务器的局域网 IP／公司域名，不能填写 `127.0.0.1`。
- [ ] **P03 准备平板 HTTPS。** 网页连续取景使用证书受平板信任的 HTTPS 地址；公司使用公司 CA。预期：浏览器没有证书警告，可申请相机权限。普通局域网 HTTP 只能测试系统相机后备，不能算连续取景验收通过。设置见 [HTTPS 与平板相机](HTTPS与平板相机.md)。
- [ ] **P04 准备试用资料。** 选一种元件，准备清楚的正品图、同款正常实物、已知明确差异样品（如有）、明显失焦图片，以及几个批量文件。试用物料统一加独立前缀，例如 `TRY001`，避免覆盖真实标准。下文型号 `SV358` 只是示例，可整体换成自己的型号。

没有实物时，可复制仓库 `fixtures/inspection/green-mat-v1/reference-crop.png` 作为正品，重命名为 `TRY001 SV358.png`；`single.png` 是对应的完整台面待检生成图。电脑点击“打开系统相机”后，若系统提供文件选择器，可选择该图验证链路。**生成图、拍屏或预设样例不作为真实平板拍摄准确率证据。**没有差异实物时，跳过真实差异准确性项，另用 I05 的预设样例测试交互。

## A · 管理员登录与入口

- [ ] **A01 登录。** 在电脑打开管理端，输入已有正品管理员账号密码。预期：进入正品标准列表。未配置正式账号的服务器本机可用页面提示的 `admin / admin123`，它只是普通试用管理员；已配置账号时使用自己的账号。
- [ ] **A02 登录错误。** 退出后输入一次错误密码，再用正确密码登录。预期：错误有清楚提示，正确登录后不残留旧错误。
- [ ] **A03 核对权限。** 普通正品管理员能看到正品标准、维护日志、回收站；看不到“人员与权限”和“检验任务”。系统负责人可以看到“人员与权限”，但同样没有管理端检验任务页。

管理员登录与平板检验登录相互独立。管理端当前用账号密码，检验端仍为明确标注的本地试用身份；公司 IDaaS 尚未接通。负责人账号准备及权限专项见 I01 和 [人员与权限](人员与权限.md)。

## B · 手工录入一条正品

- [ ] **B01 新增与预填。** 点击“新增标准”，上传 `TRY001 SV358.png`。预期：物料编号、型号按文件名预填，供应商可以留空；一个或多个空格均作为分隔符，顺序为 `物料编号 型号 [供应商]`。
- [ ] **B02 自动分析。** 上传后不要另找“开始分析”。预期：页面自动显示排队／分析中的状态；可以先保存草稿，但分析未完成不能启用。
- [ ] **B03 核对文字。** 等待完成，对照图片检查“需比对的正品丝印文字”是否逐行填写正确，图片质量和难辨字符是否有合理说明。预期：清晰成功结果的详情可折叠；存在问题时展开说明，展开左侧分析不撑大右侧表单。模型读错、漏字或误报歧义都记录反馈，不只检查有没有文字。
- [ ] **B04 保存启用。** 供应商和特殊检测说明留空。无问题时点击“保存标准”；若有待确认项，核对后选原因再保存。预期：进入详情，状态已启用，物料编号＋型号、图片和文字正确。确实看不清时先换图或保存草稿，不为跑流程强行采用。
- [ ] **B05 查询与唯一性。** 返回列表搜索 `TRY001` 或 `SV358`；另开“新增标准”尝试同物料＋同型号、但不同供应商。预期：能搜索到原记录，重复保存被阻止，原标准不被静默覆盖。返回列表即可，无需保留这条重复输入。
- [ ] **B06 草稿。** 新增另一试用编号，添加图片后先“保存草稿”。预期：管理端可继续编辑；检验端不能选到草稿。补齐资料并完成分析后“保存并启用”，才可用于新检测。另在未保存输入后重新进入，确认恢复提示右侧“×”只关闭提示，字段、图片与区域仍保留；再次进入仍可恢复。“放弃草稿”应单独确认，不因关闭提示被触发。

## C · 图片编辑与区域规则（第二遍专项）

只操作试用标准。首次可先“取消”退出验证查看，再实际保存一轮。

- [ ] **C01 直接入口。** 列表点击“裁剪”或“区域”，再从完整编辑页打开“裁剪 / 旋转”“忽略区域”“重点区域”。预期：两处都能进入对应工具，不需要反复寻找菜单。
- [ ] **C02 缩放和旋转。** 鼠标指向丝印处滚轮缩放，确认没有缩放滑杆，在选择／移动、裁剪、忽略框、重点框模式下均测试滚轮；平板用双指捏合，切换“选择 / 移动”后拖空白处移动图片；拖动图片旋转环并输入角度。预期：缩放围绕鼠标位置，旋转连续、可控，操作不会让图片丢出可找回范围；“适应”能恢复便于观察的视图。
- [ ] **C03 整件裁剪。** 用自由矩形保留整个元件及引脚，应用裁剪／旋转后应用到标准。预期：生成检测用图、沿用原分析且不再调用模型；“查看上传原图”仍能看到未经该次变换的图。编辑结果应再次保存标准后才作为正式依据。进入标准详情并重复打开，裁后图应完整适应预览区；较小裁片也能自动放大。改变窗口尺寸后仍正常，滚轮缩放后可双击或聚焦按 `0` 恢复。
- [ ] **C04 重点／忽略区域。** 在丝印区画绿色重点框，在可变编号处画黄色忽略框，给区域补充含义。点击已有框或右侧条目，拖动移动、拖四角缩放、拖圆点旋转；也试右侧角度与用途切换。应用到标准并等待分析。预期：自动填写的文字仅含重点区内且不在忽略区的内容；忽略区转写仅用于区域说明。框保持真实四边形，与图片对应；绿色表示只检查其内丝印，黄色表示忽略样品对应位置变化；说明能可靠读到时引用具体文字，读不到时不编字。再保存并重新打开，位置不变。
- [ ] **C05 互斥与失效。** 尝试让两种框重叠；随后换图或应用一次裁剪／旋转。预期：重叠被阻止；裁剪／旋转时已有框随图变换，应用后预览仍可见，模型调用数不增加。裁剪会切掉标记时有提示，不能静默丢框。只有更换照片才清空旧框并要求重新确认。
- [ ] **C06 取消与恢复。** 做一次调整后取消，重新打开检查；再试“恢复原图”。分别验证添加、移动、缩放、旋转、删除、裁剪应用和恢复原图后的撤销／重做，试一次快捷键。预期：一次拖动一步，旧位置可精确恢复；取消不改已保存标准；本轮新编辑的图片恢复到上传原图时，区域同步反向变换；旧版缺少变换记录时应提示，不猜位置。最后保存明确要采用的版本。

区域规则对实际样品的作用，可在 F 阶段用“只改变忽略编号、型号不变”和“改变重点区型号”两组真实样片核对；没有对应样片就标未测试，不用界面能画框代替识别效果验收。

## D · 批量导入、重复与暂存

准备一个小包，先 ZIP，RAR 可在 I02 单独测。只用试用编号。建议以下六张，子目录仅为区分候选，字段只取最后的文件名：

| 包内文件 | 用途 |
| --- | --- |
| `正常/TRY001 SV358 试用供应商.png` | 与 B 阶段已有标准重复 |
| `正常/TRY002 SV358.png` | 新标准、供应商空 |
| `候选A/TRY003 SV358.png` | 同批候选 A |
| `候选B/TRY003 SV358.png` | 同批候选 B，可用另一张同款照片 |
| `待补齐/命名待补齐.png` | 不完整文件名，但图片本身可读 |
| `待换图/TRY004 SV358.png` | 确实看不清的失焦图 |

如果 `TRY002` 等编号已存在，请换一组未用编号，保留各项之间的重复关系。清晰度、歧义判断以实际图片为准，不要求模型必须凑出固定的可保存数量。

- [ ] **D01 入口与模板。** 进入“批量导入”，下载命名示例 ZIP。预期：主入口为图片 ZIP / RAR，Excel／JSON 在“其他导入方式”内；命名示例与最新规则一致。
- [ ] **D02 上传预检。** 选择准备的小包，按页面提示开始预检。预期：解析六条并自动排队分析；目录名不进入物料、型号、供应商字段；错误文件名不导致可读图片丢失。
- [ ] **D03 总览与筛选。** 查看“全部”“可保存”“待确认”“重复项”“暂存条目”。预期：“全部”没有勾选列；“重复项”与其他筛选并排，能集中看到已有重复和同批候选。
- [ ] **D04 已有重复。** 在“重复项”表头用小型全选框，或只勾选 `TRY001`。预期：仅选择可覆盖的已有项，不替你决定同批候选；默认没有静默覆盖。此处只选试用编号。
- [ ] **D05 同批重复。** 对 `TRY003` 点击“比较并选择”，看两张图，选一张并“采用选中图片”。预期：每组只采用一张，其他候选留在批次中；不能同时保存两套同键标准。
- [ ] **D06 问题条目。** 筛选“待确认”，点“补齐资料”或“查看 / 处理”。预期：能看原图及具体问题，可补字段、换图或填核对原因；“保存并返回批次”后修改保留。先留至少一条未处理，验证下一步暂存。
- [ ] **D07 部分保存。** 等所选可用条目分析完成后，点击“保存 N 条，其余暂存”；有覆盖时再确认。预期：明确提示新增、覆盖和暂存数量；已保存标准可查，未完成条目没有被当作启用成功。
- [ ] **D08 恢复批次。** 点击“暂存并返回”，刷新页面，使用同一管理员继续待处理批次。预期：图片、字段、问题、候选和已保存状态均保留；已保存条目不会再创建一份。问题修改后可继续保存。
- [ ] **D09 覆盖与日志。** 搜索 `TRY001`，查看版本和“维护日志 → 查看变更”。预期：采用本批新资料，旧版本仍可追溯；真正变化的字段标题突出。若 B／C 中已有特殊说明或框，覆盖时不能悄悄沿用旧图规则。

注意：“保存一部分、其他暂存”仅用于正品录入。后面的检验批次有未完成照片时仍不能结束或回填。

## E · 平板进入并连续拍照

- [ ] **E01 进入检验端。** 平板打开 P03 的 HTTPS 地址，进入本地试用，选择“自主检测”。预期：显示试用身份及真实识别模式；不用等待 MES 接口。
- [ ] **E02 选择标准。** 搜索 `TRY001` 或实际型号，查看并选择刚启用的标准。预期：物料、型号、可选供应商正确；点缩略图能放大正品。不要误选 I05 的预设样例。
- [ ] **E03 打开相机。** 点击“拍照”，允许相机，查看后置画面。预期：可在同一页面持续取景，相册入口不显示；若失败，应有原因和“打开系统相机”后备。记录当前实际用了哪种相机。
- [ ] **E04 连拍与移除。** 连拍三张，每张先拍一个清晰元件；在拍摄页移除一张，再补拍一张。预期：无需每拍一张退出，计数及时更新；缩略图后台生成不阻塞下一张或完成，最终本次有三张。分别记录第1张和后两张的等待时间。
- [ ] **E05 完成保存。** 点“完成（3张）”。预期：返回照片总览，出现已保存提示和三张照片。只按了快门、尚未完成添加，不等于服务器已保存。
- [ ] **E06 替换与补拍。** 在总览“替换”其中一张，拍清后完成；然后“继续拍照”再加一张。预期：替换不增加照片数；补拍后合计四张，删除／替换按钮直接可见。
- [ ] **E07 横竖屏。** 在总览和拍摄页切换横竖屏。预期：主按钮、相机画面、数量和照片可见，没有文字被边缘挡住或横向溢出。拍摄页内未保存照片不要通过刷新测试，以免误丢。

## F · 真实识别与增量

- [ ] **F01 开始检测。** 对已保存照片点“开始检测”。预期：出现整图识别状态和按照片统计的真实进度，等待中页面有反馈；不用先输入聊天问题，也不要求手动裁剪。
- [ ] **F02 核对定位。** 等完成后，查看每张照片的元件数；点击图片进入详情及原图查看。预期：显示完整照片，不运行自动 CV 裁剪、不出现本轮新生成的裁片白板；核对 VLM 返回的元件数量、文字和结论，有无漏件或多算。发现错误记录原图和编号，不只看最后绿灯。
- [ ] **F03 核对真实结论。** 对照实物或人工确认的照片，检查逐行文字和结论。预期：相同内容正确识别为合格，明确差异可指出具体位置；模型自评置信度不当作准确率。没有明确差异样品时，该部分标未测试。
- [ ] **F04 增量检测。** 本批先不“完成”，再拍一张并添加，点“检测未完成部分”。预期：只处理新增照片，之前已完成结果保留，数量随实际新增元件变化。
- [ ] **F05 低质量重拍。** 补一张明显看不清的图并检测。预期：黄色“需要重拍”，无法结束本批，不把看不清直接认定元件不合格。若模型没有发现明显模糊，记录为质量漏报。用清晰照片替换后重检，不重复统计被替换照片中的元件。
- [ ] **F06 多元件（有实物再做）。** 分开摆放 4 个元件，单张拍清后检测；再视情况测 6 个。预期：逐个定位且按元件计数。当前不运行 CV 分离，由 VLM 看完整照片判断；件数或关键文字无法确认时应提醒处理。此项结果用于确定现场可接受摆放方式，不预先保证任意背景都可用。

## G · 查看结果、报告与可选修正

- [ ] **G01 总览。** 查看结论、合格／不合格数量与照片卡片；照片多时切换“紧凑预览”。预期：一眼能看到异常和未完成内容，不需要逐个打开才知道状态。
- [ ] **G02 逐件详情。** 点击照片进入元件详情，多件时点击编号切换。预期：正品和待检图、逐行字符差异清楚；“检测依据与修正记录”默认展开。返回总览不丢本批内容。
- [ ] **G03 原图放大。** 分别点击待检图和正品图，使用放大按钮、滑杆、拖动；平板测试双指缩放。预期：各自打开正确图片，能观察关键字符；缩略展示不会截掉整段丝印。
- [ ] **G04 完整报告。** 在照片总览“更多 → 查看完整报告”，上下浏览并“下载报告”。预期：照片／元件编号、文字、差异、结论和不良数一致，现场说明与人工修正如有则列出。Markdown 图片链接目前依赖本系统会话；离线附件打包及向真实 MES 上传仍待对接，不据此判为附件已接通。
- [ ] **G05 人工修正（仅测试批次）。** 在详情“修正结论”，选择合格／不合格、原因，按需补充文字后保存。预期：汇总立即按最终人工结论更新，AI 原判、修改人和原因仍保留；不要求每件都人工复核。测试性改判请写明“试用验证”，不要作为真实业务判断。
- [ ] **G06 验证计数。** 同一张照片若有两个元件最终不合格，预期不良数为 2；任一元件不合格则整批不合格。可在测试批次用人工修正验证统计，再按真实核对恢复正确结论。没有多件照片时留到 F06 后测试。

## H · 结束与再次进入

- [ ] **H01 完整性门槛。** 本轮还有待检、失败、需重拍照片时检查底部操作。预期：不能“完成本次检测”，也不能部分回填；先处理完全部已拍内容。
- [ ] **H02 完成本次。** 全部结果明确后点“完成本次检测”。预期：显示本系统已保存，合格／不合格与不良数正确；自主检测的“提交到 MES”仍置灰，由人员在电脑 MES 手工填写。当前不会向公司 MES 上传任何附件。
- [ ] **H03 返回再看。** 返回正品选择，展开“最近的自主检测”，打开刚完成的一批；刷新再看。预期：照片和结果还在，已完成轮次不会被当作空白新批次；最近入口当前保留最近 20 条。
- [ ] **H04 重检。** 打开已完成记录，点“再检一批”，任选重新拍摄或复用上一轮照片。预期：创建新轮次，旧轮次可追溯；新轮次按当前有效标准检测。当前自主模式只保存在本系统，真实 MES 重检更新待接口联调。

## I · 第二遍专项（按条件选做）

- [ ] **I01 人员权限。** 已有系统负责人时，新增一个专用试用管理员，退出后用该账号登录，核对不能管理人员；再由负责人停用，验证旧账号无法继续请求／登录，启用后恢复。预期：授权日志保留操作。只测试专用账号，不停用实际录入人员；没有负责人则按[人员说明](人员与权限.md)由部署人员准备后再测。
- [ ] **I02 RAR／Excel。** 用新一组试用编号测试 RAR；Excel 下载页面模板后填少量资料，编号／型号设文本格式，配套图片按模板说明导入。预期：同样完成分析、重复处理和暂存；前导零不丢。不要直接导入含多份示例清单的“模板资料总包”。
- [ ] **I03 强制采用。** 在测试正品中上传低质量图片，先查看分析问题；确需验证此入口时填写“仅用于试用，知悉质量问题”，确认采用。预期：不能跳过尚未完成的分析；完成后强制采用有明显标记，可筛选，日志有原因。不要把该测试标准用于实际检验。
- [ ] **I04 维护与恢复。** 删除一个专用试用标准，进入回收站“查看详情”，再执行“恢复”。预期：查看不会触发恢复；恢复不丢图和历史，维护日志人员与变更正确。只删除试用标准。
- [ ] **I05 无差异实物时的交互样例。** 在单独测试轮次用“内置预设样例”，分别体验不合格、需重拍、20 张照片和同图 20 件。预期：显示预设来源，可测试筛选、紧凑布局、编号切换和修正；这些结果不算真实模型测试。
- [ ] **I06 现场说明。** 在未结束轮次“更多 → 补充本次检测说明”，添加针对本批的说明并保存，再点检测。预期：已有元件按新说明重判，无需重拍，报告保留说明；若与标准冲突，报告醒目标明按现场指示执行。说明由人核对，不用随意指令制造实际业务合格结论。
- [ ] **I07 模拟 MES。** 切到“模拟 MES 任务”，搜索标准对应任务，切换全部／未完成／已完成并刷新，打开任务完成检测和模拟回填。预期：自动关联新标准，筛选不删除任务；回执明确为模拟，不等于公司已保存。管理端不应出现维护任务的入口。
- [ ] **I08 中断与恢复。** 仅在无人进行真实录入／检验时，用专用批次测试已保存草稿的刷新或服务重启恢复，以及网络恢复后重试上传。预期：已确认服务端保存的内容还在，失败不会显示成保存成功。相机页“完成”之前的临时照片不承诺刷新后恢复。
