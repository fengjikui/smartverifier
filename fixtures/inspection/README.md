`expected.json` 保存人工核对真值和源文件 SHA-256。当前真实定位与模型实验见 `research/real-vision/`。测试不会在工作台普通启动时自动创建任务；只有点击“试用合成样例”才加载。

`twenty-components.json` 另存 20 件样例的来源哈希、拼接坐标和预设结论。重建使用 `.venv/bin/python scripts/generate-twenty-sample.py`（Pillow），不修改前三张源图。它只用于界面和流程演示；除下述原有图片外，本轮没有生成新的器件外观或调用模型识别。

生成要求概要（不是模型测试真值）：

1. 参考：写实现场手机照片风格，灰色哑光检验台，单个黑色八引脚器件，完整引脚、缺口与定位点，清晰三行虚构丝印 SV358 / A26 / 0147；无需广告渲染、标签或测量框。
2. 差异：同类环境与封装，稍微倾斜，把第一行改为 SV385，其他两行 A26 / 0147，保持文字可人工读取。
3. 多件：同类背景，四个分离摆放的器件组成两行两列，具有不同旋转角度；左下器件 SV385，其余 SV358，后两行均 A26 / 0147。

几何测试还用程序构造空背景、多目标、边缘截断与模糊条件。这些都是受控工程验证。真实场景中的托盘、反光金属件、贴片电阻/电容、拥挤摆放、不同背景与失焦，需要后续现场照片单独评估，不能从这三张图外推效果。
