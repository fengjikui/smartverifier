# 观微 · SmartVerifier

电子元件参考图与来料外观对比的响应式交互原型，以及支持本地视觉模型的图像裁剪、旋转和识别 Agent。

## 范围

- 桌面：参考图、待检图、差异说明同屏。
- 手机：待检/参考切换，滑动比较，局部放大和拍照文件入口。
- 点击预设差异定位；切换六个演示器件，包括正常、差异、模糊状态。
- 新建对比，选择自有图片；自有图片明确显示待分析，不套用演示结果。
- 人工复核意见在当前会话中保存，可导出 JSON。
- 正品参考页与手机预览页 `/mobile`。

## 运行

```sh
npm install
npm run dev
npm run build
```

## 重要边界

网页目前是 UI 原型，尚未连接下方独立运行的本地 Agent 或其他检测模型。示例照片由 ImageGen 生成，虚构 NOVA 元件与差异用于交互演示；不是正品标样或真实鉴定证据。自有图片通过浏览器 Object URL 本地展示，不传给检测服务。照片及复核状态仅在本次页面会话中保留，刷新后重置。图片上传支持 JPG/PNG/WebP，单张最多 20 MB。

后续接模型时应由服务端保存原图、校验裁剪坐标、回传真实图像质量与差异证据。自动器件定位、图像对齐、逐颗检测、身份认证、记录持久化及 WeLink SDK 集成都不在当前原型范围。

## Agent 图像工具

新增独立的 [image-focus 工具与两轮识别 Agent](agent-tools/image-focus/README.md)，提供从原始分辨率裁剪、旋转、插值放大、整图分块和局部坐标回溯。包含 Python/CLI 接口、返回真实图片的 MCP 服务、本地 LM Studio 全图/自主裁剪识别对照和离线测试。Agent 已验证本地千问的图片识别与真实工具调用，会保存模型原文、裁片和选区供人工核对；尚未接入当前网页或元器件真伪检测服务。

现场照片放在 `images/`，识别结果放在 `outputs/`；两者与本地虚拟环境均已排除出 Git。仓库只包含代码、文档、依赖锁文件及虚构的网页演示图片。
