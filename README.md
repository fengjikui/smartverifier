# 观微 · SmartVerifier

电子元件参考图与来料外观对比的响应式交互原型。

## 范围

- 桌面：参考图、待检图、差异说明同屏。
- 手机：待检/参考切换，滑动比较，局部放大和拍照文件入口。
- 点击预设差异定位；切换六个演示器件，包括正常、差异、模糊状态。
- 新建对比，选择自有图片；自有图片明确显示待分析，不套用演示结果。
- 人工复核意见在当前会话中保存，可导出 JSON。
- 正品参考页与手机预览页 `/mobile`。

## 运行

```sh
npm install
npm run dev
npm run build
```

## 重要边界

本项目是 UI 原型，未接入 Qwen3.8-27B 或其他检测模型。示例照片由 ImageGen 生成，虚构 NOVA 元件与差异用于交互演示；不是正品标样或真实鉴定证据。自有图片通过浏览器 Object URL 本地展示，不传给检测服务。照片及复核状态仅在本次页面会话中保留，刷新后重置。图片上传支持 JPG/PNG/WebP，单张最多 20 MB。

后续接模型时应由服务端保存原图、校验裁剪坐标、回传真实图像质量与差异证据。自动器件定位、图像对齐、逐颗检测、身份认证、记录持久化及 WeLink SDK 集成都不在当前原型范围。
