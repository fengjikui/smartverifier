## 材料记录原则

- 区分**官方公开能力、我们的工程推断、实际运行结果、仍需验证的问题**。
- 每项实验保留模型/运行时版本、参数、输入哈希、人工真值、模型原文、评分、耗时口径和资源条件。
- 同时记录失败和反例，禁止只收集成功截图。修正解析器时保留模型原文和旧评分，明确说明修正了什么。
- 同一元件重复排布不能当独立样本。模型自报分数、OCR 原始分数、公开榜单成绩均不能直接称作业务准确率。
- 原图、权重、环境和完整运行记录在 Git 忽略的 `outputs/`；脚本、精简结果和研究说明在此目录。现场私有照片以后需另行约定访问与保存方式。

## 后续汇报可采用的结构

业务问题 → 任务拆解 → 候选路线 → 受控实验 → 反例与发现 → 实拍验证 → 资源与部署 → 方案选择及下一步。

最终服务器、模型、量化精度和并发目标尚未定型。迁移到 NVIDIA 后应重测图片处理、输出结构、延迟及内存，不直接套用当前 Mac 上的耗时。
